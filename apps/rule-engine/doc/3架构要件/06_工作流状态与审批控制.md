# 分包 06：工作流状态与审批控制架构要件

## 1. 目标

本分包定义服务端 Java 控制面的权威状态机、阶段实例、Gate 守卫、租约、失败修复和人工审批；memory 只能提交事件和转换请求。

## 2. 状态所有权

服务端 `CMP-SRV-002` 是根任务与阶段状态唯一所有者。memory 显示缓存不得作为放行依据，任何状态变化必须在服务端事务内完成并产生审计事件。

## 4. memory 交互合同

memory 可请求：创建任务、领取运行、上报事实、提交产物、请求 Gate、提交变更请求、请求人工审批。memory 不可请求“直接设为 PASS/RELEASED”，也不可在本地伪造服务端状态。

## 5. 故障处理

服务端事务超时或返回不确定结果时，memory 使用幂等键查询原动作；不能查询确认时进入本地待核对状态，不重复高风险副作用。
