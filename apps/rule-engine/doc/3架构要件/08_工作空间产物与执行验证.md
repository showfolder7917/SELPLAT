# 分包 08：工作空间、产物与执行验证架构要件

## 1. 目标

本分包定义 memory 本地工作空间、Git、产物、Architecture Package、任务、测试、修复和服务端摘要登记的完整链路。

## 3. 本地证据策略

服务端默认接收证据摘要、类型、大小、产生者和受控引用。需要上传完整证据时必须经过 artifact policy、大小限制、脱敏和访问控制。

## 4. Git 边界

memory 管理本地需求分支；ai-factory 只保存分支名、基线、提交摘要和审批状态，不直接执行本地 Git 命令。远程推送、PR、合并和发布均为独立外部动作。
