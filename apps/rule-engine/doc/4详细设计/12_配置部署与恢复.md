| DES ID | 配置键 | 示例 | 约束 |
| --- | --- | --- | --- |

## 3. 部署与恢复对象

| DES ID | 对象 | 设计 |
| --- | --- | --- |
| DES-DEP-001 | memory 启动 | 读取实际 OS、工程根、配置和客户端凭据，取得单实例锁后启动监听器与 Codex 连接池；API 不兼容时进入草稿模式。 |
| DES-DEP-002 | ai-factory 启动 | 参照 japanese 的 backend 子项目，先校验数据库版本再开放 HTTP 与只读页面；不启动 Agent 调度器。 |
| DES-DEP-003 | 服务备份 | 本地开发备份进入 `服务端开发数据/备份/`；服务器生产环境备份正式数据库、审计 manifest、批准治理包和配置摘要到受控外部存储。 |
| DES-DEP-004 | 本地备份 | 按 task_id 保存当前任务文档、Agent会话摘要、工作空间、审计日志、SQLite outbox、批准快照和恢复点；不备份令牌。 |
| DES-DEP-005 | 恢复顺序 | 服务数据库→审计校验→治理包→API；memory 配置→SQLite→快照→工作空间→对账。 |
| DES-DEP-006 | 版本兼容 | `GET /api/v1/ai-factory/capabilities` 返回 apiVersion、minClientVersion、features。 |
| DES-DEP-007 | 降级 | 服务不可用时 Python只允许在对应 task_id 根生成未登记草稿/候选包，不允许正式阶段、批准或结果登记。 |
| DES-DEP-008 | 成本限制 | 服务下发冻结预算；memory 每次动作前检查剩余量，超限保存恢复点。 |

## 4. 未决值

正式数据库、服务器地址、证书方案、RPO/RTO、保留期和物理目录更名在实现前必须批准；本设计给出的 H2/8091 仅为 MVP 可替换默认值。
