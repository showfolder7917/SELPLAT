固定源码目录只保存程序、人工维护或正式发布的只读资源；运行生成的任务文档、候选规则、Agent 上下文、会话、日志和证据禁止写回这里。

## 2. ai-factory Java 工程结构

结构以 `apps/japanese` 为基准：聚合目录根不承担实际 Java 编译，`backend` 是 `settings.gradle` 登记的实际 Gradle 子项目；业务模块优先，每个模块内部保持 Controller、Service、Service Impl 和 DAO 分层。

```text
apps/ai-factiory/
├─ backend/
│  ├─ build.gradle
│  └─ src/
│     ├─ main/
│     │  ├─ java/com/sp/selplat/aifactory/
│     │  │  ├─ common/config/AiFactoryModuleConfiguration.java
│     │  │  ├─ common/persistence/
│     │  │  ├─ task/{controller,service,service/impl,dao}/
│     │  │  ├─ agentregistry/{controller,service,service/impl,dao}/
│     │  │  ├─ workflow/{controller,service,service/impl,dao}/
│     │  │  ├─ approval/{controller,service,service/impl,dao}/
│     │  │  ├─ governance/{controller,service,service/impl,dao}/
│     │  │  ├─ artifact/{controller,service,service/impl,dao}/
│     │  │  ├─ gate/{controller,service,service/impl,dao}/
│     │  │  ├─ audit/{controller,service,service/impl,dao}/
│     │  │  └─ progress/{controller,service,service/impl,dao}/
│     │  └─ resources/
│     │     ├─ META-INF/
│     │     ├─ db/aifactory/sql/
│     │     └─ static/aifactory/{aifactory.html,aifactory.js,aifactory.css,i18n/}
│     └─ test/java/com/sp/selplat/aifactory/
└─ db/sql/
```

## 3. 唯一运行生成根

```text
OPTION/temp/ai-factory/
├─ 状态/{memory.db,待上报队列,快照,恢复点}/
├─ 治理/{已批准快照,服务端登记缓存}/
├─ 审计/{跨任务索引,待上报队列}/
├─ 服务端开发数据/{数据库,日志,备份}/
└─ 任务/<task_id>/
   ├─ 当前任务/{用户原始需求,需求文档,需求要件,架构要件,详细设计,实现记录,测试文档,发布材料}/
   ├─ 智能体/{角色快照,Agent会话,上下文,连接状态,心跳}/
   ├─ 工作空间/ 阶段线程/ 产物/ 门禁/ 证据/ 治理候选/
   └─ 审计日志/ 运行日志/ 恢复点/ 清单/
```

一个 `task_id` 只有一个任务根；该任务的所有文档、Agent 运行、Gate、证据和审计日志均归入该目录。跨任务目录只允许保存索引或待上报队列，不能成为任务事实的唯一副本。

## 4. 设计对象

| DES ID | 计划对象 | 详细合同 | 验证 |
| --- | --- | --- | --- |
| DES-STR-001 | `已退役本地驱动应用` | 独立 Python 工程，不注册为 Gradle 子项目；所有运行路径从 SELPLAT 工程根和配置解析。 | macOS/Windows/Linux 路径测试。 |
| DES-STR-002 | `apps/ai-factiory:backend` | 参照 japanese 的实际 Gradle application，依赖 common-core/web/service/db、sel-ui、Spring Web/JDBC、MyBatis、H2。 | 离线 Gradle 编译。 |
| DES-STR-003 | `com.sp.selplat.memory` | Python 包承载唯一流程驱动、Agent 访问、规则工厂与本地执行，不出现服务端 DAO。 | 依赖扫描。 |
| DES-STR-004 | `com.sp.selplat.aifactory` | Java 包只承载登记、API、状态、审计和可视化，不启动 Agent/Codex、不读取本地任务目录。 | 禁止依赖扫描。 |
| DES-STR-005 | `config/memory.toml` | 保存服务地址、客户端、运行根、SQLite、连接池、outbox 和证据策略；禁止令牌明文。 | 配置 Schema 测试。 |
| DES-STR-006 | `application.yml` | 保存端口、数据源、SSE、租约、限制、审计和环境；生产密钥只从外部注入。 | profile 配置测试。 |
| DES-STR-007 | 模块所有权 | Rule/Gate/Process 候选和 Runner 属于 memory；角色/Agent 登记、批准版本和结果登记属于服务端。 | 双端目录与依赖 Gate。 |
| DES-STR-008 | 构建输出 | 两工程独立构建发布；API 主版本不兼容时 memory 只允许草稿模式。 | 兼容矩阵测试。 |
| DES-STR-009 | japanese 同构分层 | Java 每个业务模块包含 controller、service、service/impl、dao；公共配置与持久化进入 common。 | 包结构扫描。 |
| DES-STR-010 | `static/aifactory/` | 静态资源目录和文件名不使用横线，页面路径固定 `/aifactory/aifactory.html`。 | 静态资源路径测试。 |
| DES-STR-011 | `OPTION/temp/ai-factory/任务/<task_id>/` | 所有可生成内容进入唯一任务根；源码目录零运行生成物。 | 污染扫描与任务归属测试。 |
| DES-STR-012 | 中文业务资源 | Markdown/配置资源允许 `RUL_中文`、`AGENT_中文`、`IDX_中文`；稳定 ID 与程序标识保持英文。 | UTF-8、NFC 与跨平台测试。 |

## 5. 命名和异常边界

- 中文路径统一 UTF-8、Unicode NFC，禁止空格、`..`、斜杠、冒号和控制字符。
- 中文文件重命名视为版本变化，必须更新索引并重新计算摘要。
- `ai-factiory` 暂保留用户给定的物理工程拼写；逻辑产品、API 和运行根使用 `ai-factory`。
- 目录尚不存在时，本详细设计只产生实施任务，不自动创建两个应用工程。
