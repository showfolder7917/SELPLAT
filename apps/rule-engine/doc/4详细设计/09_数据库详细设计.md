# 分包 09：数据库详细设计

## 1. 数据源

服务端唯一数据源名 `aiFactoryDataSource`，事务管理器 `aiFactoryTransactionManager`。结构参照 japanese，MVP 源 SQL 位于 `apps/ai-factiory/db/sql/`，构建时进入 `backend/src/main/resources/db/aifactory/sql/`；所有时间以 UTC 保存。

## 3. DAO 计划

`AiFactoryBaseDao` 绑定 AI 工厂数据源；简单表 DAO 仅继承公共 `BaseDao`。跨表事务查询集中在 `AiFactoryControlDao`，禁止 Controller 拼 SQL。

| DES ID | Java 方法 | 作用与示例 | 返回/异常 |
| --- | --- | --- | --- |
| DES-DB-019 | `claimStage(long stageId,String clientId,String tokenDigest,Instant expiresAt,long expectedVersion)` | 原子领取 STAGE-1。 | 影响 1 行成功；0 行由 Service 判断冲突。 |
| DES-DB-020 | `transitionTask(long taskId,String from,String to,long expectedVersion)` | 状态版本条件更新。 | 返回影响行数；0 表示非法/并发冲突。 |
| DES-DB-021 | `findTaskSnapshot(long taskId)` | 聚合任务、阶段、当前运行、Gate 和审批。 | 返回不可修改 Map；不存在为空。 |
| DES-DB-022 | `appendAudit(CommonParam event)` | 写 append-only 事件。 | 返回 1；previousHash 不符抛完整性异常。 |
| DES-DB-023 | `findTraceImpact(String type,String id,long version)` | 递归查询下游关系。 | 返回有序对象列表；检测循环并报告。 |
| DES-DB-024 | `invalidateGateResults(long artifactId,long newVersion)` | 将旧结果置 INVALIDATED。 | 返回影响行数；不删除历史。 |
| DES-DB-025 | `findEventsAfter(long taskId,long sequence,int limit)` | SSE 续传。 | 返回 sequence 升序列表。 |
| DES-DB-026 | `reserveIdempotency(String clientId,String key,String digest)` | 预留幂等请求。 | 返回 NEW/REPLAY/CONFLICT。 |

## 4. Agent Registry DAO

`findApprovedRole(stageId)`、`resolveActiveAgent(roleVersionId,clientId)` 和 `freezeTaskAgentBinding(runId,...)` 只查询或冻结登记；不得出现 `startAgent`、`connectCodex` 或服务器探测本地地址的方法。

## 5. 保留与归档

MVP 不物理删除任务、Gate、审批和审计。完整任务文档、证据正文和本地执行审计保留在 `OPTION/temp/ai-factory/任务/<task_id>/`；服务端只保存逻辑地址、摘要、Python上报事实和自身 API 处理审计。正式保留期、RPO/RTO 进入待确认配置，不能静默清理。
