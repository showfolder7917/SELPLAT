# 分包 09：数据模型与全链追踪需求要件

## 1. 独立交付说明

本分包定义 AI 产出工厂权威逻辑数据、版本关系和双向追踪。这里只规定业务实体和约束，不提前固定物理 DDL、字段类型、索引或类与方法。

## 2. 权威数据边界

根任务是所有阶段、产物、要件、测试、Gate、错误、审批和审计的权威串联对象。文件和 ThreadID 是跨系统标识，不能代替数据库主键。推荐架构下 Java 管理面是业务数据库唯一写入者。

## 4. 最小关系视图

```text
ai_task
 ├─ ai_task_stage ─ ai_stage_run ─ ai_artifact ─ ai_gate_result
 ├─ ai_requirement_item ─ ai_trace_link ─ 架构/设计/任务/测试/Gate对象
 ├─ ai_progress_event / ai_error_log / ai_audit_event / ai_approval
 └─ ai_retrospective ─ ai_improvement_proposal ─ Rule/Gate/Process版本
```

## 5. 分包验收

架构交付必须提供逻辑 ER、聚合根与所有权、状态版本、引用完整性、唯一性、归档、双向查询和影响传播设计，并证明不存在 Java/Python 双写同一业务表。
