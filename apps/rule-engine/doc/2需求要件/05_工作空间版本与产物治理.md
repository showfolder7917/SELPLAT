# 分包 05：工作空间、版本与产物治理需求要件

## 1. 独立交付说明

本分包定义根任务、Thread、工作空间、Git 分支、标准文件、产物登记、Architecture Package 和版本失效。它为其他分包提供唯一的可交接制品合同。

## 2. 统一业务合同

- 一个用户需求对应一个根任务、一个不可变 `root_thread_id`、一个需求级工作空间和一个需求级分支。
- 每次阶段执行使用独立 `stage_thread_id` 和运行记录。
- 数据库中的 artifact 记录是产物路径、版本、摘要和状态的权威来源。
- 文件名用于人工识别，不能替代数据库主键或审批事实。

## 4. 标准输入与输出

- 输入：根任务、已批准阶段产物、目标工程、基线、权限和风险策略。
- 输出：隔离工作空间/分支、登记产物、固定摘要和可交接 Architecture Package。
- 前置：命名安全、目标路径在工程边界内、前置 Gate/审批有效。
- 异常：摘要不一致、包过期、路径逃逸、分支冲突或写集合重叠时阻断。

## 5. 分包验收

架构交付必须覆盖标识生成、父子线程、文件安全命名、工作区/分支生命周期、artifact 注册、摘要、原子写、包签发、失效、变更请求和恢复查询。
