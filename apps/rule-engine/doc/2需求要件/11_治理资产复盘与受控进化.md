# 分包 11：治理资产、复盘与受控进化需求要件

## 1. 独立交付说明

本分包定义长期治理资产边界、事实到复盘再到改进提案的流程，以及 Rule、Gate、Process 新版本的受控发布。它明确禁止建设需要 Agent 全量阅读的第五类全局知识堆积层。

## 2. 资产边界

长期资产只包括：Log Library（事实）、Rule Library（原则）、Gate Library（检查）、Process Library（流程与职责）。任务复盘和未批准提案按任务归档，不自动成为长期有效知识。

## 4. 输入、输出与异常

- 输入：不可变事实、Gate/测试证据、质量指标和人工反馈。
- 输出：任务复盘、未批准提案或批准的新治理版本。
- 前置：事实可校验，分析角色与原执行角色按权限隔离。
- 异常：无事实、重复提案、容量超限、影响未知或审批缺失时阻断发布。

## 5. 分包验收

架构交付必须给出四类资产模型、事实/分析隔离、复盘 Schema、三类提案、30 条容量治理、审批发布、版本生效和无第五类知识资产的检测机制。
