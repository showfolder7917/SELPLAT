# 分包 10：管理面、Worker 与实时进度需求要件

## 1. 独立交付说明

本分包定义推荐的“Java 管理面 + Python 执行面 + SelUI 页面 + Codex 执行器”运行边界、数据库单写、任务领取、心跳、产物/错误上报和 SSE 实时进度。它不固定方法名称和物理表结构。

## 2. 系统边界

- SelUI：只通过受控 API 展示和操作任务，不直连数据库。
- Java 管理面：鉴权、事务、状态机、角色、调度、业务数据库唯一写入和 SSE。
- Python Worker：领取阶段、加载角色/规则/包、启动 Codex、执行文件/测试、上报事实。
- Codex：在当前角色权限和 Architecture Package 范围内工作，不直接更新工作流状态。

## 4. 输入、输出与异常

- 输入：阶段运行、固定角色/规则/包、工作空间、受控任务和 API 凭证。
- 输出：心跳、进度、产物、错误、完成事实，由管理面持久化和裁决。
- 前置：Worker 已认证且阶段可领取。
- 异常：API 中断、心跳丢失、进程崩溃、重复领取、过期包或完成结果不确定时进入恢复/人工核对。

## 5. 分包验收

架构交付必须包含组件边界、信任边界、API 合同、认证与幂等、单写事务、领取/心跳/STALE、SSE 顺序恢复、错误事实和 Codex 启动时序。
