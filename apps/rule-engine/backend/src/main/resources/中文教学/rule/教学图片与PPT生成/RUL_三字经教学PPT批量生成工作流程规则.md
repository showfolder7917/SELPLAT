# 《三字经》教学PPT批量生成工作流程规则（竖版与横版）

## 一、适用范围

本规则用于把核定版《三字经》注音DOCX制作成竖版或横版无文字系列底图和文字可编辑的教学PPT。连续蒙学经典按语义篇章和短句分页，不使用古诗的作者、故事、核心意境等固定栏目，也不得自行添加“第一章”等原文不存在的章节标题。横版制作同时加载同目录的`RUL_横版教学PPT通用排版与检查规则.md`。

## 二、正式输入与长期成果

1. 唯一文字输入为核定版DOCX；生成前记录路径和SHA-256。
2. DOCX转换出的分页JSON、渲染图、联系表、失败废稿和日志均进入当前项目的可删除临时文件目录。
3. 通过检查的无文字底图进入`<当前项目>/底图/系列底图/`。
4. 可编辑PPT长期稿进入`<当前项目>/PPT排版/批量稿/`。
5. 最终PPT、系列底图副本、清单、验证报告和压缩包进入`<当前临时目录>/最终输出（可重新生成）/`。

## 三、DOCX解析与分页

1. 按DOCX表格顺序提取逐字拼音、汉字和句末标点，禁止凭记忆补写正文。
2. 每个三字短句保留三个拼音、三个汉字及一个标点，共7个可编辑文字对象。
3. 常规正文页排8句，即24个汉字；左右双排，每排两句，共四行。
4. 末页不足8句时按实际句数排版，不补空句、不重复正文、不缩小全套字号。
5. 当前核定版的固定统计为：120个源表格、478句、1434字、60页正文；加1页封面，共61页。
6. 分页JSON必须保存页码、源表格号、短句、拼音、汉字、标点、主题、构图变体和底图文件名。

## 四、系列底图策略

1. 正式套图采用13张无文字竖版底图：1张封面，6个主题各A/B两种构图。
2. 六个主题为：启蒙教育、孝悌礼仪、天地常识、经史典籍、历史兴替、劝学修身。
3. 每个主题连续使用10页，A/B按页交替；同主题保持纸张、框线、人物、色彩和笔触一致，构图与教学场景有变化。
4. 底图统一为1053×1494像素。正文安全区为约`x=80–710、y=300–920`，该区域必须浅、净、连续，不得出现人物、屋檐、深色树枝、器物或高对比山石。
5. 底图不得出现汉字、拼音、数字、印章、水印、牌匾字或伪文字。
6. 底图失败按现有通用机制处理：同一问题最多自动尝试3次；第3次仍失败则保存证据、登记失败并继续后续页面，不得阻塞整批。

## 五、正式文字版式

1. 页面尺寸：1053×1494，竖版。
2. 标题：`三字经`，宋体类中文字体，76磅、加粗、深棕色`#5B3A22`；参考框为`left=128, top=140, width=548, height=92`。
3. 正文左句起点`x=110`，右句起点`x=410`；单字位宽78，标点窄列宽42。
4. 常规四行顶端依次为`400、535、670、805`。
5. 拼音：Arial，23磅，颜色`#756653`；汉字：Songti SC，54磅，颜色`#2F2922`；标点：Songti SC，38磅，颜色`#4B4034`。
6. 拼音在上、汉字在下，每字独立可编辑；标点单独使用窄列，不得占用完整汉字字位。
7. 末页6句使用三行并适度放大纵向间距，当前参考行顶为`445、615、785`。
8. 文字位置以正式005竖版双句样例为准；不得烧入底图，也不得把整页文字转成图片。

## 六、PPT构建顺序与对象规则

1. 每页必须先加入一张独立的全页底图，再加入标题、拼音、汉字和标点对象，确保文字始终位于底图之上。
2. 禁止复制页面后替换共用媒体引用；该方式可能使全部复制页同步变成同一底图。
3. 禁止在已有文字页最后追加全页图片后仅依赖置顶命令修复；导出时可能仍出现底图遮住文字。
4. 常规正文页应有57个文本框：标题1个，加8句×7个；末页按实际句数计算。当前整套应有3407个文本框和61张全页底图。
5. 封面仅保留无文字底图和居中的可编辑标题，不增加未经核定的副标题或章节名。

## 七、自动检查与重试

1. 结构检查：61页、61张底图、3407个文本框；页码连续，封面后正文顺序与DOCX一致。
2. 内容检查：逐页比较分页JSON与PPT中的拼音、汉字和标点；差异必须为0。
3. 几何检查：运行PPT溢出检测；任何文字越页、重叠、遮挡或压边均不通过。
4. 渲染检查：必须把最终PPTX实际渲染成61张图片，不得只检查生成器预览。
5. 视觉检查：先查看61页联系表，再全尺寸检查封面、每个主题A/B代表页、末页及所有可疑页。
6. 必查项目包括：标题位置、双排对齐、拼音与汉字对应、标点窄列、插画不侵入安全区、正文与场景之间留白协调。
7. 同一构建问题最多自动重试3次。第3次仍失败时记录问题、最后稿和截图，继续能完成的后续工作；整批结束后统一交付失败清单。
8. 修正后必须重新运行结构、内容、溢出和实际渲染检查，不能只复看局部截图。

## 八、最终交付

1. 压缩包包含：最终可编辑PPT、13张系列底图、页序与底图映射、生成清单、最终验证报告。
2. 压缩包不得包含源DOCX、构建脚本、图片生成中间文件、联系表、局部截图或失败废稿。
3. 压缩后必须执行完整性测试，记录PPT和压缩包的SHA-256。
4. 正式文件名使用版本号；已确认成品不得无提示覆盖。

## 九、本次正式批次经验

1. 底图06、07、11的首稿因插画或建筑侵入正文安全区被拒绝，均在第2次生成通过。
2. PPT第1次构建因复制页共用媒体引用导致底图同步替换；第2次因后加全页底图遮住文字失败；第3次采用“每页从零创建、先底图后文字”通过。
3. 当前批次最终统计为61页、13张长期底图、3407个文本框、478句、1434字，逐项内容差异为0。

## 十、横版双页教学模式

### 10.1 篇章边界

1. 横版模式以4个三字短句为一篇，即两个带句号的完整句；不得沿用竖版每页8个短句的容量。
2. 第一篇为`人之初，性本善。性相近，习相远。`。
3. 第二篇从`苟不教，性乃迁。教之道，贵以专。`开始；禁止把第一篇和第二篇混在同一原文页或同一讲解页。
4. 后续篇章按同样方式以4个相邻三字短句组成；如语义明显跨越边界，必须先人工或规则层确认，不得只按数量硬切。

### 10.2 双页结构

1. 每篇固定使用两页：第一页为原文页，第二页为译文、智慧解读和生活启示页。
2. 相邻两页共用一张按当前篇释义生成的无文字底图。
3. 不同篇正式底图不得重复，风格统一但人物动作、场景和象征内容必须区分。
4. 原文页保留作品标题`三字经`，默认不显示`原文`题签。
5. 讲解页不显示`三字经`标题，也不显示`原文`题签，只保留`译文、智慧解读、生活启示`三个栏目。

### 10.3 第一篇横版参考坐标

1. 画布和底图为1672×941。
2. 标题按人工微调样板使用`left=120, top=67, width=830, height=140`，Songti SC 96、加粗，深棕色。
3. 原文两行顶端为`y=270、491`；左句起点`x=140`，右句起点`x=560`。
4. 字列宽112；拼音Arial 28，汉字Songti SC 82，标点Songti SC 52。
5. 讲解页题签顶端为`y=83、365、628`；正文顶端为`y=155、436、698`，三段正文统一使用`left=120, width=940`，题签29，正文Songti SC 36、1.5倍行距、首行缩进两个汉字位。
6. 以上数值用于当前1672×941底图，后续底图必须在相同安全区原则下实际渲染光学校正。

### 10.4 横版专项检查

1. 每篇原文对象必须恰好来自4个三字短句；后4句不得提前进入当前篇。
2. 原文页`三字经`标题数量必须为1，`原文`题签数量必须为0。
3. 讲解页`三字经`标题数量必须为0，三个栏目题签必须各为1。
4. 第一篇两页当前参考对象统计为2张全页底图、35个可编辑文本框。
5. 字号必须随内容量增加而放大；从8短句减为4短句后，不得保留原小字号造成大块空白。
6. 横版通用底图、安全区、构建、重试、渲染和交付要求按`RUL_横版教学PPT通用排版与检查规则.md`执行。
7. 讲解页三段正文必须严格统一左边缘和宽度；已废弃“生活启示正文横移到题签右侧”的旧方案，不得从008复制该布局。
8. 实际渲染后必须逐段截取局部图，确认首行第一个字与续行第三个字对齐、行距达到1.5倍、标点不孤行、文字在深色插画前结束。

### 10.5 当前通过样例

`PPT排版/样例/009_三字经_横版第一篇人工微调款式复刻样例.pptx`作为横版第一篇的当前排版参考。009严格复刻用户人工微调图：标题96、原文行顶270/491、正文36、1.5倍行距、首行两字缩进、三段正文统一`left=120, width=940`，并保留人工确定的两行断句。008及更早样例均降为历史比较稿，不作为后续批量生成依据。
