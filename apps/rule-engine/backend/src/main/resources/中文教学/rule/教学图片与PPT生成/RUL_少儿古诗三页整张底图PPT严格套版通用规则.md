## 二、不可变核心原则

1. 标准古诗默认使用三页，每页只使用一张完整的无文字整页底图。
2. 三张底图分别独立构图，均为`1672 × 941`，在 PPT 中从`(0,0)`铺满整页，禁止拉伸、露边和只铺半页。
3. 第二、三页可以在视觉上包含多个圆角小场景、作者画像、儿童动作或知识图册，但这些内容必须在 imagegen 阶段融合成一张完整底图，不能在 PPT 中再拼贴九张图片。
4. 大型素材板只能作为人物、服装、配色、笔触和场景参考；禁止直接裁切素材板局部作为正式底图或正式插画。
5. imagegen 只生成无文字底图；标题、作者、原文、拼音、栏目名、说明、页码和导航必须保持 PowerPoint 可编辑。
6. 插画中禁止出现汉字、拼音、字母、数字、印章、牌匾文字、书本伪文字、页码、水印和假按钮。
7. 同一首诗的三页保持角色设定、时代服饰、色彩和笔触统一，但三页构图必须不同，禁止反复铺同一张底图。
8. 已有底图只有在尺寸、语义、留白、角色一致性和整页构图全部通过时才能复用；素材板、裁片、半幅扩展稿和旧成人风格底图均不视为合格成品。

## 三、每首古诗的三张整页底图

### 3.1 第一页：原文与拼音

底图职责：用一个完整主场景解释诗的核心画面，并提供连续、明亮、低细节的原文排字区。

PPT 可编辑内容：诗题、朝代作者、原文、逐字拼音、标点、底部导航和`NNN 诗名 · 1/3`。

要求：

1. 画面主体通常位于右侧或右下方，左侧保留大面积浅色安全区；如诗意更适合反向构图，可左右镜像，但整批应保持稳定视觉节奏。
2. 原文汉字和拼音是全组三页中最高的教学视觉层级。
3. 每个拼音、汉字和标点分别使用可编辑对象；标点使用窄字位。
4. 长诗按核定句子增加原文续页，不通过缩小文字或压缩行距强塞。

### 3.2 第二页：诗意、字词与画面理解

底图职责：形成完整横版教学画面；左侧或其他低细节区域为诗意与字词留白，另一侧把 2–4 个诗句小场景自然融合进整页构图。

PPT 可编辑内容：诗名与“读懂诗意”、诗意、字词理解、画面理解题签、各小场景说明、导航和`NNN 诗名 · 2/3`。

要求：

1. 小场景之间可用柔和水彩边缘、圆角窗格或自然景物分隔，但整张图必须保持统一背景、统一光线和统一画风。
2. 每个小场景解释不同诗句或重点词义，禁止重复同一人物姿态和同一构图。
3. 小场景的说明文字不得烧入图片，应预留清晰标签区供 PPT 叠加。
4. 左侧正文区与小场景主体都必须避开底部导航安全区。

### 3.3 第三页：品读与拓展

底图职责：形成一张完整的品读拓展画面；为情感与寓意、作者简介、思考互动、知识拓展提供稳定文字区，并在其余区域融合作者画像、儿童观察或学习动作、诗意物象和无字知识图册。

PPT 可编辑内容：诗名与“品读与拓展”、四个栏目正文、编号、导航和`NNN 诗名 · 3/3`。

要求：

1. 作者画像符合时代身份和服饰，不伪造可辨识的书中文字。
2. 儿童人物年龄、脸部风格和配色与前两页一致。
3. 视觉元素必须支持栏目含义，不放与诗词无关的通用装饰。
4. 文字区内背景保持低细节；复杂人物和道具不得进入正文安全区。

## 四、imagegen 生成流程

1. 从核定 DOCX 或核定 JSON 读取编号、标题、朝代、作者、原文、拼音和标点。
2. 为当前诗编写诗意、字词、情感、作者、互动和知识内容，再据此规划三张整页底图。
3. 选择参考样例中最接近的三页作为构图基准，并把现有素材板明确标记为“角色和画风参考”，不能标记为裁切源。
4. 每一页单独调用一次 imagegen；默认每首三次调用，长诗续页按实际页数增加。
5. 提示词必须明确：`1672×941 横版整页无文字底图`、8 岁以下少儿水彩绘本、当前诗意、主体位置、文字安全区、底部导航安全区、角色一致性、禁止文字和水印。
6. 第二、三页需要多个视觉模块时，明确要求“多个小场景已经融合在同一张完整横版画面中”，禁止素材板、照片墙、九宫格和独立贴片感。
7. imagegen 结果立即复制到项目正式底图目录；项目所用图片不得只留在`.codex`生成目录。
8. 原始结果、提示词、失败稿和渲染检查图放入项目对应的可删除临时文件目录。

## 五、PPT 严格套版流程

1. 完整审计参考 PPT，并为三类输出页分别映射到已确认的整张底图参考页。
2. 背景图使用一张`1672×941`图片铺满整页，不增加额外图片拼贴层。
3. 按参考页实际位置叠加可编辑标题、正文、拼音、题签、说明和导航。
4. 只有背景对比不足时才增加暖白或浅米色文字衬板；衬板固定为 40% 透明度（60% 不透明度），仅覆盖文字安全区。
5. 文字衬板不得大面积遮挡人物、主场景和小场景，不得把整页改成不透明白色卡片。
6. 页面导航至少包含“上一篇、总目录、下一篇”，并写入真实内部幻灯片跳转。
7. 每次修改后重新渲染最终 PPTX，不得只检查构建阶段截图。

## 六、允许与禁止

允许：

- 根据当前诗意重新生成三张不同整页底图；
- 为标题长度和原文长度做小范围坐标或字号调整；
- 长诗增加原文续页；
- 对已有合格主场景做受控扩图，但必须输出完整`1672×941`新底图并保持人物不变；
- 第二、三页在一张整图中融合多个小场景。

禁止：

- 默认生成九张独立图片再在 PPT 中拼装；
- 从大型素材板裁切局部作为正式素材；
- 将半幅图片放大、拉伸或用空白补齐为整页；
- 在 PPT 中用多张图片对象模拟一张整页底图；
- 把相同底图机械复用于同一首诗的三页；
- 把文字烧入底图；
- 让人物、树木、建筑、题签或说明文字进入导航区；
- 复用与当前诗词、年龄或时代不匹配的旧素材。

## 七、完成后检测

### 7.1 底图检查

- 每首默认正好三张完整底图，长诗续页除外；
- 每张均可解码，尺寸为`1672 × 941`，无黑边、露边、拉伸和半幅构图；
- 三页角色、服装、配色和笔触一致，构图各不相同；
- 第二、三页的小场景已自然融合，没有素材板、拼贴或裁片痕迹；
- 所有文字安全区和底部导航安全区清晰可用；
- 没有伪文字、数字、印章、水印和假按钮。

### 7.2 文字与排版检查

- 标题、作者、朝代、原文、拼音、标点与核定来源逐字一致；
- 诗意、字词、情感和知识只对应当前诗；
- 无压线、越界、重叠、意外换行和文字落入复杂插画区；
- 文字衬板全部为 40% 透明度（60% 不透明度）；
- 原文页字号与参考样例同等级，第二、三页正文不因内容过多被压缩成小字。

### 7.3 PPT 与导航检查

- PPTX 结构完整，全部文字保持可编辑；
- 每页只含一张正式整页背景图，另有文字、衬板和导航对象；
- 内部导航按钮数量、目标页和页码状态全部正确；
- 逐页渲染最终 PPTX 并以原始尺寸检查；
- 运行越界检查并修复所有非预期重叠、裁切和占位符残留。

### 7.4 背景替换后的文字完整性检查

1. 把旧页面替换为新的整张底图时，只允许替换唯一的全页背景图；标题、作者、拼音、原文、题签、正文、场景说明、导航和页码定位等非背景对象不得被删除。
2. 如果新底图预留区与旧文字锚点不同，必须先建立“页面字段 → 新底图安全区”的完整映射并重新生成文字层；禁止先批量删除旧对象，再只恢复少数标签或导航。
3. 第二页必须至少核对：页面标题1个、诗意题签1个、诗意正文1个、字词题签1个、字词正文1个、画面理解题签1个、场景说明4个，以及完整导航和页码定位。
4. 第三页必须至少核对：页面标题1个、情感与寓意、作者简介、思考互动、知识拓展四个题签及四组正文，以及完整导航和页码定位。
5. 核定数据中字段非空而PPT对应文本为空、对象缺失或页面预留卡片整体空白时，一律判定为失败；“背景好看”“对象未越界”或“页面可打开”不能替代内容完整性检查。
6. 批量稿必须生成逐页字段清单，把核定字段和PPT可编辑文本逐项比对；不得只抽查少数样例页后推定全批次正确。
7. 文字对象存在但落在错误分镜、人物、深色纹理或其他栏目安全区时，按内容缺失同等级处理，必须修正后重跑全部检查。

### 7.5 分镜标签锚点与可读性检查

1. 四幅分镜的说明文字必须位于各自预留的浅色标签槽内，并与对应画面一一匹配；不得直接压在泥土、水面、人物服饰、树叶或高对比纹理上。
2. 标签槽坐标必须按当前底图实际测量；禁止沿用旧素材板或旧模板的纵坐标，导致下排文字漂到插画中央而标签槽留空。
3. 标签文字使用深色字和高不透明度浅色衬板；原始尺寸渲染时笔画必须连续清楚，不得以缩略联系图“看起来有字”作为通过依据。
4. 场景说明必须保持在标签槽四周的安全边距内，不能贴边、压线、被导航条遮挡或与相邻分镜串位。

### 7.6 分镜主体完整度检查

1. 每个分镜必须完整呈现当前说明所指的主要人物、动物、动作或物件；头部、躯干、关键肢体、主要道具和动作关系不得被分镜边缘无意切断。
2. 主要主体与分镜边缘默认保留不少于约28像素的视觉呼吸空间；特写只有在不影响动作理解且明确属于构图设计时才可例外。
3. 四个分镜必须分别解释四个不同画面或动作；禁止用同一主体姿态重复填充，也不得用羽毛、脚掌等局部碎片替代需要完整主体才能理解的教学画面。
4. 底图生成后必须逐格查看原始尺寸；发现解剖关系异常、主体重复、关键部位裁断、画面与标签语义不符或标签槽不可用时，先修底图再排字。
5. PowerPoint中的`cover`铺满不等于主体完整；底图本身已经把主体裁断时，禁止通过缩小整张底图、留白边或遮盖文字来伪装修复。

### 7.7 三页文字视觉平衡与同级字号检查

1. 原文页的诗题、朝代作者、逐字拼音和原诗必须作为一个阅读组落在底图浅色安全区内；应根据当前底图插画交界动态调整整组水平位置，默认优先向留白侧移动，禁止让最右侧汉字、拼音或标点贴近、压住或进入人物、山水、树木等高对比插画。
2. 原文阅读组在安全区内部保持视觉居中，不得机械使用整页中心；标题、作者与诗文采用同一视觉中心轴。原文页禁止增加覆盖诗文的大面积蒙版，只有文字对比实际不足且不遮挡主景时才允许使用专项透明度衬板。
3. Logo必须逐页选择安全空位，可位于左上角、标题右侧空隙或其他不影响阅读的位置；禁止整批固定同一坐标后遮挡标题、作者、正文、分镜主体或栏目题签。Logo与最近文字或图片主体之间必须保留可见安全距离。
4. 第二页“诗意”和“字词理解”的绿色题签保持既定大小和位置；需要统一的是题签下方的正文内容。“字词理解”正文必须与“诗意”正文使用相同字体、字号、颜色和行距，项目符号、词语和解释不得单独缩小。
5. 第二页正文基准以人工确认样例的“诗意”正文为准；在1672×941页面中，同级正文通常使用约23–24像素字号。内容较多时优先优化换行、增加文本高度或精简重复表达，禁止让自动适配把“字词理解”缩成一眼可见的小字。
6. 第二页四幅分镜说明的浅色底框必须按文字可见宽度自适应；短标签不得沿用过宽固定框。底框围绕对应分镜中心对齐，与分镜底边、相邻分镜和底部导航保持稳定距离，文字在底框内水平、垂直视觉居中。
7. 第三页“情感与寓意、作者简介、思考互动、知识拓展”四组正文属于同一层级，必须统一字体、基准字号、颜色和行距；禁止“知识拓展”或任一栏目因自动缩放而明显小于其他三组。
8. 第三页带序号正文使用不会触发PowerPoint自动列表的中文全角序号格式，例如`1．`、`2．`、`3．`；序号必须与对应句子在同一行开始，禁止序号单独占行、缩进漂移或列表悬挂。
9. 卡片正文以“题签下方至卡片底边上方”的正文安全区为基准进行视觉垂直居中。短文本应适当下移，长文本按实际行数计算整体高度后居中；同页四块正文起始纵坐标允许不同，禁止为了机械对齐把短文全部挤在顶部或把长文压到底边。
10. 视觉居中必须使用最终PPTX渲染后的可见字形包围范围判断，不能只相信文本框的`verticalAlignment`。正文与题签、左右边框和卡片底边的最小留白必须稳定，文字不得贴线、压角花或显得上下失衡。
11. 页面整体布局以标题、文字组、插画主体、Logo、题签、图注和底部导航形成的视觉重心为准；对象全部在画布内但出现明显偏左、偏右、偏上、偏下、局部拥挤、大片无意义空白或同级字号不一致时，仍判定为失败。
12. “一眼可见不合理”属于正式失败条件，包括但不限于：文字落入错误分镜、正文与题签距离突变、四卡片中单块字号明显更小、Logo贴住标题、图注框远宽于文字、文字贴边、序号错位、同组内容中心轴不一致、插画与文字视觉重量严重失衡。
13. 批量验收必须先查看全部页面联系图识别系统性漂移，再逐页查看原始尺寸；原文页、第二页正文区、分镜标签区和第三页四卡片区均须局部放大确认。联系图看不清文字时不得据此宣布通过。

## 八、重试与失败处理

1. 同一底图或同一页面的同类问题最多自动重试三次。
2. 第一次优先修正提示词中的主体位置、文字安全区和导航安全区。
3. 第二次对照参考样例校正整页比例、视觉重量和小场景融合方式。
4. 第三次只处理仍存在的明确问题；失败后保存最后稿、提示词、检查图和失败原因并登记。
5. 单首失败不得阻塞后续诗词；登记后继续下一首。
6. 文字排版问题只修改 PPT；只有底图主体残缺、语义错误、出现伪文字或无法提供安全排字区时才重新生成图片。

## 十、《寻隐者不遇》纠偏案例

《寻隐者不遇》只生成三张整页底图：

1. 原文拼音页：诗人在松树下询问童子，画面为左侧原文安全区与右侧完整山林人物主场景。
2. 诗意字词页：一张完整横版画面中融合“松下问童子、师父采药、云深山林、寻找踪迹”等 2–4 个小场景，并保留诗意和字词排字区。
3. 品读拓展页：一张完整横版画面中融合贾岛画像、童子或儿童观察、松树深山和无字知识图册，并保留四个栏目排字区。

此前生成的九张独立插画及其拼装 PPT 仅作为失败对照，不得继续作为正式模板或后续批量输入。

## 十一、批量执行

1. 先完成《寻隐者不遇》三张整页底图和三页严格套版，验证规则纠偏有效。
2. 已符合本规则的《咏鹅》《春晓》等页面可直接复用；未符合者按三页整张底图标准重做。
3. 后续按 DOCX 编号从小到大连续生成；每首完成后自动验证并继续。
4. 三次重试仍失败的项目登记后跳过，不中断整批。
5. 批量完成后优先评估文件体积和使用场景：若总稿过大，应按年级或册次拆为分册交付；若体积可控，才合并为一个带目录和篇间导航的可编辑 PPT。
6. 分册交付时，每册封面标题必须写明当前年级或册次，不得继续使用“1—6年级”一类总稿标题。
7. 分册交付后必须逐册检查页数、可编辑文字、封面标题、目录按钮、上一篇/下一篇/本册目录按钮、链接目标是否越界、渲染页数和溢出检测。
8. 分册或总稿更换整张底图后，必须对全部页面执行字段完整性清单检查；不得把“页面数量正确、内部链接正确、无越界”当作文字层已经正确迁移。
9. 批量视觉检查先看全部页面联系图识别空白卡片、错误锚点和版式漂移，再对每一张讲解页和拓展页查看原始尺寸；存在问题的诗不得因同册其他页面通过而被整体标记为通过。
