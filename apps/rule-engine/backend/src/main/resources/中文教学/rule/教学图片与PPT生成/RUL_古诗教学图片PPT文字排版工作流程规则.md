# 古诗教学图片 PPT 文字排版工作流程规则

## 一、适用范围与引用方式

1. 本规则用于把核定版 DOCX、核定清单 JSON、审校教学内容和正式无文字底图制作成可继续人工编辑的 PowerPoint。
2. 本规则只负责 PPT 中的文字解析、文字排版、分页、渲染检查、修正、归档和交付；无文字底图的生成与修正继续遵守同目录的`RUL_古诗无文字底图生成工作流程规则.md`。
3. 标题、作者、原诗、标点和拼音的内容正确性继续遵守同目录的`RUL_古诗教学图片生成全流程规则.md`。
4. 当交付目标明确为 PPT 时，本规则中的 PPT 工具、PPT 字号和 PPT 验收方式，优先于全流程规则中面向 Pillow 成图的排字工具和数值参数；该优先级只限 PPT，不改变 JPG、PNG 或 PDF 成图规则。
5. 本规则由`MEMORIES/ai/protocol/RULE_INDEX.md`按任务类型最小加载；未命中古诗PPT任务时不得自动读取。
6. 面向8岁以下儿童且任务涉及三页整张底图或严格样例复刻时，必须同时加载同目录的`RUL_少儿古诗三页整张底图PPT严格套版通用规则.md`；本规则继续约束可编辑文字和PPT验收，整页底图形态与样例复刻以该专项规则为准。
7. 后续同版式 PPT 必须先读取本规则，再以本规则坐标、公共母版和本轮验证输出为视觉基准；禁止凭记忆重新猜测坐标。

## 二、固定目录

`<当前项目>` 固定解析为 `OPTION/temp/中文教学/项目/<源DOCX基名>/`；`<当前临时目录>` 固定解析为 `OPTION/temp/中文教学/教学图片与PPT生成/<项目临时分类名>/`。开始排版前必须先读取项目说明，确认源 DOCX、编号范围、成果归属和临时分类名。

```text
核定 DOCX：用户指定的核定版 *.docx
核定清单：<当前临时目录>/PPT排版数据（可由DOCX重新生成）/*_核定清单.json
当前项目教学内容：<当前项目>/PPT排版/批量稿/*_教学文案核心_*.json 或 <当前项目>/参考资料/当前项目内容/
正式无文字底图：<当前项目>/底图/NNN_标题.png
PPT 单首样例：<当前临时目录>/PPT排版样例/
PPT 批量可编辑稿：<当前项目>/PPT排版/批量稿/
最终输出（可重新生成）：<当前临时目录>/最终输出（可重新生成）/
失败与修复经验：公共/通用失败与修复经验.md
临时构建与检查资料：<当前临时目录>/PPT渲染检查/ 或 <当前临时目录>/PPT合并分块/
```

## 三、工具分工

| 阶段 | 指定工具 | 产物与职责 |
|---|---|---|
| DOCX 读取 | 工作区捆绑文档运行时；优先复用既有核定清单 | 读取标题、朝代、作者、原诗、标点和逐字拼音 |
| 内容读取 | JSON 解析 | 读取故事、解读、核心意境、生活启示和页脚 |
| PPT 制作 | 工作区捆绑 Node.js + `@oai/artifact-tool` 的纯 JavaScript ES module | 生成可编辑文本框、题签和内嵌底图 |
| PPT 渲染 | PowerPoint/LibreOffice 实际 PPTX 渲染链及 `render_slides.py` | 把最终 PPTX 重新渲染为逐页 PNG |
| 结构检查 | `slides_test.py` + PPT 对象检查 + ZIP 完整性检查 | 检查越出画布、对象缺失、文件损坏和媒体嵌入 |
| 视觉检查 | `view_image` 原始分辨率整页和局部裁切 | 检查字体、换行、留白、压线、遮挡和视觉重心 |
| 最终打包 | 支持 UTF-8 中文文件名的系统 ZIP 工具 | 打包最终通过稿、清单和验证报告 |

强制要求：

1. 禁止使用 `python-pptx` 制作正式 PPT。
2. 禁止使用图片模型生成需要核定的汉字、拼音、标题、作者、页码或教学文案。
3. 禁止把文字烘焙进背景图片；除无文字底图外，全部文字必须是 PowerPoint 可编辑对象。
4. 正式无文字底图必须以二进制方式嵌入 PPT，不得仅保存外部链接。
5. 中间构建脚本、检查 PNG、对象清单和裁切图不得留在正式样例或交付目录。
6. `PPT排版数据（可由DOCX重新生成）` 缺失时，必须从核定 DOCX 重新生成核定清单；当前项目教学内容缺失时按目标年龄重新生成，再继续自动排版，不得把可重建数据缺失判定为源数据丢失。
7. 用户明确要求品牌版、封面或角标时，使用 `中文教学/assets/品牌/新思度华文学堂.png` 作为二进制嵌入图片；未明确要求时不得自动加入，且不得遮挡可编辑教学文字、拼音或正文安全区。

## 四、完整执行顺序

```text
确认源 DOCX 和输出范围
→ 读取或生成核定清单
→ 校验标题、作者、原诗、标点和逐字拼音
→ 读取与当前源和年龄匹配的教学内容；缺少时自动生成当前项目内容 JSON
→ 校验教学内容字段、编号、标题和目标年龄后自动继续，不等待人工确认
→ 匹配 NNN_标题 正式无文字底图
→ 测量实际画布、边框和插画安全区
→ 执行分页预检
→ 使用可编辑 PPT 对象排字
→ 导出 PPTX
→ 运行页面溢出和文件完整性检查
→ 使用最终 PPTX 重新渲染每一页
→ 查看整页和六类局部裁切
→ 发现问题后修正并重新执行全部检查
→ 通过后进入样例、批量稿或最终输出目录
→ 正式批量完成后生成压缩包
```

## 五、输入内容与对应关系

1. 标题、朝代、作者、原诗、标点和拼音只能来自核定版 DOCX 或由该 DOCX 生成并已核对的核定清单。
2. 禁止重新调用拼音库猜测或替换核定拼音。
3. 每个汉字必须与对应拼音保持同一 token；标点必须是独立 token 且无拼音。
4. 故事、解读、核心意境、生活启示和页脚只有在内容文件明确属于当前源 DOCX、当前编号与当前年龄层时才可复用；来源不明、属于其他年级或其他项目的数据一律不得进入当前 PPT。
5. 缺少扩展内容时，必须根据当前核定原诗重新生成适合目标年龄的 AI 教学文案，并在生成清单中标明 AI 生成来源；AI 来源标签用于追溯，不构成人工审核门槛。
6. 自动生成内容完成编号、标题、字段和目标年龄校验后，必须立即进入分页预检、PPT 排版、渲染检测和合并流程，不等待人工确认。
7. 自动生成内容仍须满足字段完整、标题编号匹配、文字可读和版面可容纳要求；结构或排版不合格时按本规则重试，不得用“后续人工再改”跳过质量检查。
8. 文件编号必须与 DOCX 中的篇目顺序一致，使用三位编号 `001–999`。
9. PPT 中所有对象必须使用稳定名称，至少包含：
   `poem-title`、`poem-author`、`label-original`、`poem-<行>-pinyin-<列>`、`poem-<行>-character-<列>`、`label-story`、`story-text`、`label-interpretation`、`interpretation-text`、`label-core`、`core-text`、`label-life`、`life-text`、`footer-text`。

## 六、画布、背景和锚点

1. PPT 画布宽高比必须与正式无文字底图完全一致。
2. 当前样板画布为 `1054 × 1492`；其他尺寸必须按实际底图同比例换算，禁止直接拉伸。
3. 背景图必须铺满整页且保持在最底层，不得改变裁切、比例、色彩或插画位置。
4. 排字前必须测量标题框、主卡片、左中框、右中框、核心意境框、生活启示框和页脚框的实际边界。
5. 底图经过任何重新生成、裁切或缩放后，全部锚点必须重新测量。
6. 所有文字框必须位于对应内容框内，并与真实边框、角花和插画保持安全距离。
7. 结构验证通过不等于视觉通过；文本框坐标正确但字形看起来偏上、偏下或偏向一侧时，仍判定失败。
8. 横版明亮风格优先采用全幅插画铺满画布；文字安全区直接使用画面中的浅色留白，只有对比不足时才加浅暖色底板。
9. 文字底板的 PowerPoint 透明度通用标准为10%（不透明度90%）；命中少儿古诗三页整张底图专项规则时改为40%透明度（60%不透明度）。底板必须与正文保持协调内边距，禁止混淆透明度和不透明度。
10. 同一首诗的页面允许根据内容采用不同的编辑构图，但必须保持标题字体、题签样式、颜色和插画风格一致，并以实际渲染后的视觉平衡为最终依据。

### 6.1 横版明亮风格的教学分页

1. 信息完整的古诗教学样例默认使用三页：第一页为“题目、作者、原文和逐字拼音”，第二页为“诗意、字词理解和画面理解”，第三页为“情感与寓意、作者简介、思考互动和知识拓展”。
2. 原文页的汉字和拼音必须拥有全组页面中最高的视觉层级，不能为了容纳说明文字而缩小原诗。
3. 第二、三页不机械复制原文页坐标；根据栏目文字量和插画主体位置，可采用上下分区、左右分栏或单块编辑区，但不得把正文压到画面边缘或插画主体上。
4. 参考图只用于信息密度、明亮气质和视觉节奏，不得把参考图中的文字、结构或装饰直接烧入底图。
5. 自动生成的扩展内容必须饱满但简洁，每个栏目只服务当前诗篇；内容过多时增加页面，不通过缩字和压缩行距强塞。
6. 面向8岁以下儿童时，采用明亮少儿绘本或启蒙教材风格：人物表情亲切、轮廓清楚、颜色轻快，避免成人水墨、沉暗古画和仅有装饰性山水的版面。
7. 三页整张底图各司其职：第一页表现诗中主场景并为大字原文留出连续浅色区；第二页在一张完整底图中融合与诗意、重点字词和场景对应的2至4个小景或分镜；第三页在一张完整底图中融合作者肖像、儿童观察或学习动作及知识图标以支持互动拓展。
8. 同一首诗的三页保持角色设定、色彩和笔触统一，但每页必须使用独立构图，不得把同一张完整底图反复铺在三页上。
9. 第二页的“字词理解”必须做到图文语义对应，不能只放一张通用花鸟图；场景分镜需要配简短可编辑说明，文字不得烧入插画。
10. 少儿版文字应短句化、分层清楚；诗意先讲清发生了什么，字词解释使用儿童可理解的表达，拓展问题以观察、动作模仿和生活联想为主。
11. 旧PPT、旧扩展JSON、其他学段资料和历史中间稿只能作为需要排除的对照，不能作为当前项目内容源；当前小学少儿版只允许核定清单提供标题、作者、原诗、标点与拼音，教学文案必须来自当前项目重新编写的内容文件。
12. 每首诗可以使用一张无文字少儿插画素材板统一角色与笔触，但素材板只作为参考；正式成果必须重新生成三张完整横版无文字底图，禁止裁取素材板局部作为正式图片。同页与相邻页不得重复同一主体、道具组合或近似构图。

## 七、字体与字号标准

当前 `1054 × 1492` PPT 样板使用下列基准；这是 `@oai/artifact-tool` 的像素字号，不得与 Pillow 字号直接比较。

| 文字角色 | 字体 | 基准字号 | 颜色与字重 |
|---|---|---:|---|
| 诗题 | `Songti SC` | 48 | 深棕、粗体 |
| 朝代作者 | `Songti SC` | 21 | 深棕、常规 |
| 栏目题签 | `Songti SC` | 23 | 白色、粗体 |
| 原诗汉字 | `Songti SC` | 42 | 深棕、常规 |
| 逐字拼音 | `Arial Unicode MS` | 16 | 棕灰、常规 |
| 故事正文 | `Songti SC` | 22 | 深棕、常规 |
| 解读正文 | `Songti SC` | 22 | 深棕、常规 |
| 核心意境 | `Songti SC` | 21 | 深棕、常规 |
| 生活启示 | `Songti SC` | 20 | 深棕、常规 |
| 页脚 | `Songti SC` | 20 | 中棕、常规 |

字体规则：

1. 正文不得使用过粗宋体、黑体或系统未知回退字体。
2. 拼音字体必须完整支持 `ā á ǎ à ē é ě è ī í ǐ ì ō ó ǒ ò ū ú ǔ ù ǖ ǘ ǚ ǜ`。
3. 字体缺失或声调符号缺字时，停止当前篇目并记录失败；禁止静默替换。
4. 文字过多时优先改换行、调整文案层级或增加页面；禁止无限缩小字号。
5. 同一角色在整批中必须保持同一字体、字号、颜色和字重。

## 九、标题与作者排版

1. 标题必须单行，不得自动换行。
2. 标题按实际可见字形水平居中，不得只依赖文本框中心。
3. 标题与标题框上、下边线必须保留自然留白，不得压线。
4. 朝代和作者使用 `【朝代】作者` 格式，内容必须与核定数据一致。
5. 作者行不得贴住标题框底线，也不得贴近主内容框上边线。
6. 标题或作者较长时，先扩大可用文本宽度；仍放不下时才按同角色最小字号或多页方案处理。

## 十、原诗与逐字拼音排版

1. 每个有拼音的汉字建立独立拼音文本框和独立汉字文本框。
2. 拼音必须位于对应汉字正上方并水平居中。
3. 汉字列基准宽度为 `62`；标点窄列基准宽度为 `26`。
4. 标点不得创建拼音文本框，不得占用完整汉字列宽。
5. 每句先按汉字列和标点窄列计算真实总宽度，再在主诗列内独立居中。
6. 连续相同拼音必须保留清楚间距，例如 `xiàng xiàng` 不得粘连。
7. 拼音不得缺少声调，不得与相邻汉字错位。
8. 汉字、拼音和标点不得侵入右侧主题插画。
9. 原诗跨页时只能在核定句、行或段边界分页，禁止拆开汉字与拼音，禁止把标点单独留在下一页。

## 十一、栏目题签和正文排版

### 11.1 通用标准

1. 题签必须完整位于内容框内，与上、左边框保持一致内边距。
2. 同级题签的宽度、高度、字号、颜色和圆角保持一致。
3. 正文左边缘必须与同组栏目保持一致，不得忽左忽右。
4. 正文与题签之间、正文与底边之间、正文与插画之间必须保留可见留白。
5. 正文不能只堆在左上角并在中间制造无意义空洞；应通过合理行长、行数和插画避让形成左右平衡。
6. 文字与插画至少保留约 `20` 像素安全距离；淡化插画也不得直接穿过文字笔画。
7. 禁止出现引号、顿号、逗号或词组被生硬拆开，例如不得把 `“浮、` 和 `拨”` 分成不自然的两行。

### 11.2 诗意故事

1. 当前样板优先使用三行“上宽下窄”结构。
2. 第一行可利用插画上方空间；越靠近右下插画，行长应越短。
3. 不得把每行切得过短而在文字与插画之间留下大块机械空白。
4. 若三行无法容纳，不得强行缩小到不可读字号；改用四行安全区或续页。

### 11.3 诗句解读

1. 当前样板优先使用三行。
2. 每行长度应相近，但必须优先保证词组、引号和标点完整。
3. 解读文字不得侵入右侧书卷、笔筒等一体化插画。
4. 插画占用过大且文字无安全区时，先记录底图问题；仅在用户授权时局部修正底图。

### 11.4 核心意境

1. 当前样板优先使用单行横向排布。
2. 单行应从左侧正文基线自然延伸，在右侧插画前收束。
3. 禁止为了填满空白而加入未经审校的新内容。
4. 单行放不下时可改为两行，但必须重新检查上下留白和插画距离。

### 11.5 生活启示

1. 当前正式样板优先使用单行横向排布。
2. 正文与核心意境使用统一左边距和相近视觉基线。
3. 句子必须在右侧山水插画前自然结束，不得盖住亭台或山峰高对比区域。
4. 单行放不下时，允许两行；两行整体必须垂直居中，第二行不得贴近底框。

### 11.6 少儿古诗三页横版正文的动态布局

1. 三页整张底图项目中，第二页“诗意”和“字词理解”正文必须使用同一文本样式对象或同一组明确参数；两者的字体、基准字号、颜色、字重和行距必须完全一致，绿色题签不随正文调整。
2. “字词理解”项目符号与正文使用同字号；项目符号、词语、冒号和解释保持统一缩进。禁止为了容纳内容只缩小项目符号列表，而上方诗意仍保持大字。
3. 第三页四个栏目正文使用统一基准字号。正文框的纵坐标不得固定为一个机械值，应先测量文本实际行数和可见高度，再在题签下方正文安全区内做光学垂直居中。
4. 正文动态布局顺序固定为：保持同级字号 → 清理异常换行和自动列表 → 调整合理行宽与行距 → 在安全区内垂直居中 → 必要时精简重复表达或增加页面；禁止先启用自动缩字。
5. 原文页的文字中心轴取当前浅色阅读安全区中心，不取整张幻灯片中心。标题、作者和全部诗行作为一组同步平移，保证最靠近插画的文字仍有清楚呼吸空间。
6. 场景图注底框按文本实际长度计算宽度并围绕对应分镜中心放置；底框与文字使用固定内边距，短文案不得产生空旷长条。
7. 每次批量修正后必须逐页比较同类对象：原文阅读组中心轴、第二页两组正文的可见字号、四个图注框宽度、第三页四卡片正文高度与上下留白。任何肉眼明显不一致都必须修正，即使自动越界检查通过。

## 十二、页脚视觉居中

1. 页脚必须使用独立可编辑文本框。
2. 页脚水平居中，并与左右内边框保留安全距离。
3. 页脚必须按“可见字形”视觉居中，不能只相信 PowerPoint 的文本框垂直居中属性。
4. 当前样板页脚基准位置为 `[323,1346,408,48]`。
5. 每次调整页脚后必须从最终 PPTX 重新渲染，并单独裁切页脚区域检查。
6. 检查标准是文字可见像素到页脚框内侧上、下边界的留白基本一致。
7. 字体引擎不同导致视觉偏移时，以用户实际使用的 PowerPoint 截图为最终标准；可按 `2–4` 像素做光学回调。
8. 未查看页脚局部图前，禁止声明页脚通过。

## 十三、文字过多与多页排版

1. 正式绘制前必须按实际字体、实际字号、实际锚点执行分页预检。
2. 任一内容块在最低可读字号和安全行距下仍无法进入对应区域时，必须增加页面。
3. 禁止通过以下方式强塞内容：无限缩小字号、压缩行距、裁掉句子、让文字越框、让文字覆盖插画。
4. 第一页优先保留标题、作者、原诗起始内容和故事入口。
5. 续页必须重复标题、作者、页码和跨页栏目的题签。
6. 原诗只能在句、行或段边界分页；故事和解读不得出现孤行。
7. 同一首诗多页文件或导出图片使用两位页码：`NNN_标题_第01页`、`NNN_标题_第02页`。
8. 多页必须复用同一首诗已审核底图或审校后的续页底图变体，禁止逐页随机更换风格。
9. 横版逐字原文页先按实际字格计算整行宽度；超出正文安全区时优先在`，。；？！`处拆成新的显示行，拼音、汉字和标点必须作为完整 token 同步移动。
10. 原文页每页最多四个显示行；总行数无法整除时必须均衡分页，例如5行分为3+2、6行分为3+3、9行分为3+3+3，禁止4+1式单行悬空末页。
11. 一页少于四行时，按全部显示行的组合包围高度在正文安全区内垂直居中；不得继续沿用四行页的固定首行坐标而在下半部形成大面积空洞。

## 十四、生成后全面检查

每次修改后必须重新执行全部检查，不得只看刚修改的区域。

### 14.1 内容检查

- 标题、朝代、作者与核定数据一致。
- 原诗汉字、标点、行序完整。
- 每个拼音与对应汉字一致，声调完整。
- 故事、解读、核心意境、生活启示和页脚来源可追溯。

### 14.2 结构检查

- PPT 画布与底图比例一致。
- 背景完整嵌入且只出现一次。
- 所有文字对象可编辑且稳定命名。
- 没有对象越出幻灯片画布。
- PPTX ZIP 结构完整，可重新打开。
- PPT 中嵌入背景的 SHA-256 与正式底图一致。
- 合并课件的封面入口、分组目录诗目按钮、上一篇、目录和下一篇按钮均有稳定对象名，并写入真实的内部幻灯片关系。
- 内部点击动作数量、幻灯片关系数量和链接映射数量必须完全一致；所有目标页码必须位于正式总页数范围内。
- 大批量课件因无损裁切图导致导出内存不足时，可以把PPT专用裁切副本转换为高质量JPEG；正式无文字原图和已审核插画不得被替换或降质。

### 14.3 整页视觉检查

- 标题、作者没有压线或层级拥挤。
- 主诗视觉份量与右侧插画平衡。
- 拼音、汉字、标点没有粘连、错位或异常大间隔。
- 故事、解读没有生硬断行或大块无意义留白。
- 核心意境、生活启示与右侧插画平衡。
- 页脚视觉居中。
- 全页字体、字号、颜色和题签风格统一。

### 14.4 必查局部裁切

每页必须从最终 PPTX 的实际渲染图生成并查看：

1. 标题与作者区。
2. 原诗与拼音区。
3. 诗意故事区。
4. 诗句解读区。
5. 核心意境与生活启示区。
6. 页脚区。

局部裁切图只作为内部检查证据，禁止放入正式交付目录或最终压缩包。

## 十五、修正、重试和失败登记

1. 任一检查失败后，修正对应 PPT 文字对象，并重新执行内容、结构、整页和全部局部检查。
2. 仅文字错位、断行、字号、留白或视觉重心问题，不得重新生成底图。
3. 只有插画实际侵入安全区且单靠文字无法解决时，才允许在用户授权后局部修正无文字底图。
4. 同一篇同一问题最多自动尝试三次。
5. 第三次仍失败时，保存最后失败稿和验证证据，写入失败记录，然后继续下一首，禁止阻塞整批。
6. 失败记录必须包含编号、标题、页码、三次原因、最后 PPT 路径、局部截图路径和建议人工调整方式。
7. 人工调整完成后必须重新执行完整检查，不能因人工修改而跳过验收。

### 16.2 批量可编辑稿

### 16.3 最终输出

1. 最终 PPT、PDF、图片、清单、验证报告和压缩包进入 `<当前临时目录>/最终输出（可重新生成）/`；它们属于可由核定 DOCX、正式底图和排版规则重建的派生成果。
2. 已人工确认的正式成品默认不得无提示覆盖；修正版使用递增版本号。
3. 用户明确要求覆盖仍在评审中的单首样例时，可以覆盖样例文件，但必须重新执行完整检查。
4. 最终压缩包名称使用：
   `<源DOCX基名>_古诗教学图片PPT_最终版_YYYY-MM-DD_vNN.zip`。
5. 压缩包仅包含已通过的 PPT、要求交付的 PDF/图片、页序清单、生成清单和最终验证报告。
6. 压缩包不得包含构建脚本、临时图片、失败稿、局部裁切图、缓存或源 DOCX。
7. 压缩后必须执行完整性测试、UTF-8 中文文件名检查、清单数量核对和 SHA-256 记录。

## 十七、正式准入条件

只有同时满足以下条件，PPT 才能标为通过：

1. 核定文字和逐字拼音全部正确。
2. 背景图与正式无文字底图一致且完整嵌入。
3. 全部文字均为可编辑对象。
4. 无压线、越框、遮挡插画、异常断行或大块失衡留白。
5. 主诗标点使用窄列且各句独立居中。
6. 核心意境、生活启示和页脚符合当前正式样板。
7. 多页预检和页序检查通过。
8. 最终 PPTX 实际渲染后的整页与六类局部裁切全部通过。
9. 页面溢出、PPTX 完整性、对象清单和背景哈希检查通过。
10. 正式目录中只保留要求交付的文件，不混入检查中间件。
11. AI 自动生成的扩展文案只要目标年龄、结构、内容来源记录和全部版面检查通过，即可进入批量 PPT 与合并 PPT；人工审校属于后续可选优化，不属于生成准入条件。
12. 当前项目不得包含其他学段或其他源 DOCX 的标题、原诗、拼音、扩展文案和插画；必须对当前核定清单逐篇检查标题、作者、全部原文 token 和拼音 token。
13. 合并课件的实际页数、目录起始页、每首诗首页、全部内部链接和渲染页数必须相互一致；任何一个导航按钮缺失、重复或越界都不得交付。

## 十八、当前《咏鹅》样板经验摘要

1. 主诗汉字需要足够视觉份量，但不能侵入右侧白鹅插画。
2. 标点必须使用窄字位；首句 `鹅，鹅，鹅，` 不得因标点占满汉字列而显得松散。
3. 故事采用上宽下窄三行，可以利用插画上方空间并减少中部空洞。
4. 解读采用三行，并保持引号、词组和标点完整。
5. 核心意境、生活启示使用单行时，与右侧插画形成最稳定的横向平衡。
6. 页脚必须经过实际 PowerPoint 截图的光学校正，几何居中不等于视觉居中。
7. 用户提供的实际 PowerPoint 截图优先于生成器预览和缩略图判断。
8. 每次局部修正后都必须重新检查整页，避免相邻区域产生回归。

## 十九、连续蒙学经典的规则分流

《三字经》等连续短句经典不套用古诗的故事、解读、核心意境和生活启示栏目。制作《三字经》时必须改用同目录的`RUL_三字经教学PPT批量生成工作流程规则.md`；通用的可编辑文字、实际渲染、三次重试、失败后继续和最终压缩包检查仍保持一致。
