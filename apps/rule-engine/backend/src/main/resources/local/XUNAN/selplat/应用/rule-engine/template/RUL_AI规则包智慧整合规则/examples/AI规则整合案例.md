# AI 规则整合案例

## 输入问题

规则正文仍引用迁移前程序路径，但当前程序已经移动到语言原生 common 目录。

## AI 判断

1. 旧程序路径不存在。
2. 当前目录存在同名且通过测试的权威程序。
3. 这是引用迁移问题，不是删除整条规则的证据。

## 修正方式

1. core 保持冻结。
2. common 生成待人工审查补丁。
3. 当前 XUNAN 立即通过用户覆盖规则使用新路径。
4. 运行索引加载、目标程序和相关回归测试。
5. common 合并后再删除临时用户覆盖。

## 禁止方式

- 不因旧路径失效而删除仍然有效的业务规则。
- 不复制一份新程序掩盖迁移问题。
- 不直接让 AI 写入 common。
