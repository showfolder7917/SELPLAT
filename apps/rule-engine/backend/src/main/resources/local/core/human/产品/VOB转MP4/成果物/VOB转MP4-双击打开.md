# VOB转MP4-双击打开

## 作用

- 说明如何通过双击脚本直接打开 `PySide6` 视频转换界面

## 脚本位置

- `./apps/rule-engine/backend/src/main/resources/local/core/human/产品/VOB转MP4/成果物/VOB转MP4-双击打开.command`

## 使用方式

1. 在 Finder 里找到 `VOB转MP4-双击打开.command`
2. 双击脚本
3. 脚本会自动定位到工作区根目录并打开视频转换界面

## 默认行为

- 自动打开 `PySide6` 视频批量转换界面
- 默认勾选 `始终置顶`
- 默认扫描目录：`./OPTION/`
- 默认输出目录：`./OPTION/`
- 默认日志目录：`./OPTION/tmp/log/`
