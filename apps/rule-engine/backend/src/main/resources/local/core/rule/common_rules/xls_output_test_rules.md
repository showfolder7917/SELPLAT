# XLS Output Test Rules

## 说明

- 本文件用于约束 Excel / XLSX 工作簿在生成、重写或批量修改后的测试与验收行为
- 本文件适用于详细设计、表结构定义、数据库设计及其他模板驱动型工作簿交付场景
- 本文件聚焦“生成后必须验证什么、如何留下证据、哪些情况必须判失败”，不替代各类工作簿本身的结构规则

<!-- 本规则解决“文件生成成功就被当成完成，但实际 sheet 未填满、模板残留或版式不可读”的问题；适用于所有正式 xlsx 交付场景；业务含义是把 xlsx 验收从落盘成功提升为结构、内容和可视化都要通过，并以专属键标识作用域避免跨文件覆盖 -->
xls_output_test_rule_scope = xls_output_post_generation_verification

## 强制规则（Mandatory）

<!-- 生成或重写 xlsx 后必须执行成品验证；适用于新增、修改、重画模板或批量写入场景；业务含义是禁止把文件保存成功当作交付通过 -->
xls_output_must_run_post_generation_test = true

<!-- xlsx 验证必须至少覆盖文件可打开、sheet 结构、关键内容和可视化版式四层；适用于所有正式工作簿交付；业务含义是避免只验其中一层就收口 -->
xls_output_test_must_cover_file_structure_content_and_visual_layout = true

<!-- 只验证文件存在或导出成功不构成 xlsx 通过；适用于所有导出场景；业务含义是防止“有文件无质量”的伪通过 -->
xlsx_file_saved_successfully_is_not_sufficient_for_pass = true

<!-- 若工作簿由模板复制或参照模板生成，验证时必须检查模板贴合度和残留示例值；适用于模板驱动场景；业务含义是避免系统名、示例业务或旧页签残留到新成品 -->
template_driven_xls_output_must_verify_template_fit_and_remove_sample_residue = true

<!-- xlsx 可视化验证必须使用渲染预览图、截图或等价可视化证据；适用于所有存在排版和合并区的工作簿；业务含义是避免只看单元格值而忽略实际显示效果 -->
xls_output_visual_verification_must_use_rendered_preview_or_screenshot = true

<!-- 若用户通过截图或预览反馈指出工作簿问题，不能只修当前文件，必须判断是否需要同步升级生成能力、规则或验证链；业务含义是避免同类版式问题反复人工修 -->
visual_feedback_on_xls_output_must_trigger_upgrade_assessment = true

<!-- xlsx 成品验证必须记录证据路径；适用于所有正式交付；业务含义是后续可复核验证是否真实执行 -->
xls_output_test_must_record_evidence_paths = true

<!-- xlsx 验证若发现空白主区、模板占位未替换、竖排碎字、截断不可读、关键 sheet 缺失或系统名错误，必须判失败并继续修正；适用于所有正式工作簿交付；业务含义是把常见失效样式直接列为硬失败 -->
xls_output_test_must_fail_on_blank_placeholder_truncated_or_wrong_metadata = true

## 验证要求

1. 文件层必须确认最终 `xlsx` 可生成、可保存，并落在预期交付路径。
2. 结构层必须检查 sheet 数量、sheet 名称、关键页签角色和必要区块是否存在。
3. 内容层必须检查关键区域有值，且项目系统名、功能名、表名、接口名等元信息已经替换掉模板示例值。
4. 可视化层必须至少查看关键页的渲染预览图、截图或等价可视化证据，确认文字未被截断、合并区未错位、主表区未大片留白。
5. 若工作簿由模板复制生成，必须额外检查不存在旧系统名、旧业务名、旧页签名、旧示例说明等模板残留。
6. 若工作簿包含横向合并区、流程步骤区、字段映射区或说明区，必须检查这些区域在实际显示中仍然可读，不得退化成只剩编号或竖排碎字。
7. 验证结果必须记录实际检查动作、通过/失败结论，以及预览图、截图、结构检查结果文件或等价证据路径。
8. 若用户截图或预览反馈证明当前问题具有重复性，必须把对应修复回写到生成能力、规则文件或验证流程，而不是只修当前工作簿。
9. 若无法完成预览或截图验证，必须说明阻塞原因，并至少完成结构检查和关键区域值检查，同时明确剩余风险；不得宣称完全通过。

## 使用说明

- 当任务是“生成 Excel / XLSX 文档成品”而不是只讨论规则时，除专项工作簿规则外，应同时加载本规则。
- 当任务要求“截图验证”“预览检查”“生成后必须测试”“模板贴合度校验”时，优先加载本规则。
- 若任务同时涉及网页页面测试与工作簿测试，网页部分继续使用 `CODE_TEST_RULES.md`，xlsx 成品部分使用本规则，不相互替代。
