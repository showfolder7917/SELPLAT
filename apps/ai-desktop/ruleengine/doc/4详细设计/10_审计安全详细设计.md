## 3. 权限矩阵

生产 Agent 可写本层产物；Gate Runner 只读受检快照；Fix 只写指定对象；Evolution 只写候选包；批准者只做决定；Release Agent 只生成材料。提交、推送、合并和生产发布分别授权。

## 4. 审计哈希

`event_hash = SHA-256(canonical_json(event_without_hashes) + previous_hash)`；canonical JSON 使用 UTF-8、键排序、无多余空白。纠错通过 `CORRECTION` 事件引用原 event_code。

## 5. 事实等级与目录

- `LOCAL_REPORTED`：Python/Agent 在本地任务目录产生的执行事实。
- `SERVER_OBSERVED`：Java实际收到 API 请求、完成校验或拒绝的事实。
- `SERVER_VERIFIED`：Java验证了客户端身份、序号、版本和摘要，不代表亲自执行本地动作。
- `APPROVED`：独立批准者作出的决定。

每个 task_id 的完整本地审计在 `OPTION/temp/ai-factory/任务/<task_id>/审计日志/`；跨任务 `审计/` 只保存查询索引和待上报队列。Java不能宣称直接观察到 Codex、文件写入或本地测试。
