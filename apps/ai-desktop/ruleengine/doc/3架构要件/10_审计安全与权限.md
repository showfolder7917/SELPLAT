# 分包 10：审计、安全与权限架构要件

## 1. 目标

本分包定义本地事实采集、服务器集中审计、哈希完整性、身份与最小权限、HTTP 信任边界、敏感信息和高风险动作。

## 3. 身份模型

- 人工身份：稳定用户与审批主体。
- 客户端身份：某台已登记 memory 实例。
- 运行身份：role_id + agent_id + stage_run_id。
- 服务身份：ai-factory API 和内部 Runner。

每次请求必须能追踪到上述身份组合，禁止只使用一个长期共享 API Key 表示所有 Agent。

## 4. 证据与隐私

服务端默认不保存完整本地源码和敏感证据。证据引用必须带摘要、访问策略和保留策略；临时下载使用短期授权并记录审计。
