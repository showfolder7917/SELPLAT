# rule-engine 辅助历史区

本目录只保存可丢失的辅助素材和历史记录，不属于生产规则、Python 能力、测试、清单或客户规则包。

目录结构：

- `素材/`：非权威图片、Excel、示例数据及人工参考资料。
- `历史记录/`：升级明细、迁移清单、旧规则和冲突处理记录。

强制边界：

- 删除整个 `history/` 后，启动、规则加载、构建、测试、门禁和交付结果必须保持不变。
- 生产索引、`requires_rule_ids`、Python 能力和构建脚本不得依赖本目录。
- 当前有效事实必须保留在正式 `rules/`、`python/`、`tests/` 或 `manifest/` 中。
- 运行必需或影响稳定复现的资源不得存放在本目录。

权威约束由 `AI_RULE_PACKAGE_INTELLIGENCE_RULES` 承载，本 README 只说明目录用途。
