# 古诗无文字底图生成工作流程规则

## 一、适用范围

本规则只负责生成、修正、检查和归档古诗教学图片的无文字一体化底图。

本规则不负责标题、作者、原诗、拼音、故事、解读、页脚或页码排版；所有核定文字必须在后续确定性排版阶段加入。

本规则由用户或执行者手动引用，不加入全局自动规则索引。

## 二、固定目录

`<当前项目>` 固定解析为 `OPTION/temp/中文教学/项目/<源DOCX基名>/`；`<当前临时目录>` 固定解析为 `OPTION/temp/中文教学/教学图片与PPT生成/<项目临时分类名>/`。项目说明必须登记临时分类名，编号、底图、输出和临时文件不得跨项目混用。

```text
锁定母版：公共/样板底图/古诗教学图片_空白一体化母版_v1.png
项目专用参考资料：<当前项目>/参考资料/
编号标题数据：<当前临时目录>/PPT排版数据（可由DOCX重新生成）/*_核定清单.json
AI 临时稿：<当前临时目录>/图片生成中间文件/<YYYY-MM-DD_批次名称>/

```

## 四、完整执行顺序

```text
篇目清单预检
→ 查询正式底图是否已经存在并通过
→ 建立当批图片生成中间文件目录和映射清单
→ 新生成时使用锁定空白母版；已有合格主体时可对原图做受控扩图
→ 立即把当前项目原始结果复制到可删除临时文件目录
→ 无文字检查
→ 栏目完整性和文字安全区检查
→ 固定框线检测
→ 原始分辨率整图检查
→ 通过则进入人工工作底图
→ 失败则局部修正或从母版重生
→ 三次失败后登记并继续下一首
→ 批次结束后核对编号、清单和临时文件
```

## 五、生成前检查

1. 从 `<当前临时目录>/PPT排版数据（可由DOCX重新生成）` 中的核定清单读取编号和标题，文件编号必须与源 DOCX 位置一致；目录不存在时先从该项目登记的核定 DOCX 重新生成。
2. 检查 `<当前项目>/参考资料/` 中是否有当前 DOCX 项目专用的视觉参考、已确认插画或样例内容；这些资料只能服务当前项目，不得自动跨项目复用。
3. 检查 `<当前项目>/底图/NNN_标题.png` 是否已经存在并通过验证。
4. 已有正式合格底图时默认跳过，禁止重复生成造成风格漂移。
5. 确认锁定母版存在、可解码且尺寸为当前批次标准尺寸。
6. 建立 `<当前临时目录>/图片生成中间文件/YYYY-MM-DD_批次名称/`。
7. 建立当批映射清单，至少记录：编号、标题、imagegen 原文件名、项目临时文件名、尝试次数、结果状态和最终路径。
8. 若已有素材板包含通过审核且与当前诗词匹配的主场景，应先判断能否通过“受控扩图”形成全屏底图；能扩展时禁止重新设计人物、动作和主题内容。

## 六、imagegen 生成要求

1. 每首诗必须从锁定空白母版开始，不得以其他诗词成品底图作为生成母版。
2. 顶部标题框和底部页脚框必须保持完全空白。
3. 固定结构必须为：一个上部大内容框、两个并排中内容框、两个下部横向内容框。
4. 五个内容框都必须有与当前诗词语义匹配、彼此不同的小景，不允许任何一个内容框完全空白。
5. 插画只能在每个内容框的右侧、右下角或底部景线自然淡入。
6. 每个内容框左侧至少保留 55% 的浅色干净排字区域；长诗或长说明计划可提高到 60%–65%。
7. 插画必须与边框保持安全距离，不得压线、越框、遮挡角花或制造第二套假边框。
8. 插画必须使用统一宣纸底色、水墨工笔、相近颗粒、透视、光线和低饱和配色，不得呈现贴图卡片感。
9. 同页不同栏目不得重复同一主体、道具组合或近似构图。
10. 全图禁止汉字、拼音、字母、数字、题字、印章、牌匾字符、旗帜文字、页码、品牌和水印。

### 6.1 既有主场景受控扩图

1. 素材板只有右侧主场景可用、左侧是分格小图时，可把整张素材板作为 imagegen 编辑输入：锁定右侧主场景，把左侧分格区域替换为与右侧连续的山林、天空、庭院或水面。
2. 提示词必须明确“保留人物数量、脸部、服饰、动作、道具、树木和时代环境，不重新设计主体”；只允许补全缺失场景和低对比文字安全区。
3. 扩展后左侧约52%–60%应为连续、明亮、低细节区域，不得残留分格边框、拼贴接缝、重复人物、伪文字或第二套构图。
4. 成功扩图只作为当前页的完整全屏底图；同一首诗的讲解页和拓展页必须分别生成不同整页构图。面向8岁以下儿童并命中三页整张底图专项规则时，讲解页和拓展页中的小景必须在 imagegen 阶段融合进各自完整底图，禁止在 PPT 中拼贴或以素材板裁切片替代。
5. 受控扩图完成后必须检查：画布尺寸、全屏连续性、被锁定主体一致性、文字安全区、接缝、伪文字和四边覆盖情况。

## 七、标准提示词骨架

```text
把参考图作为不可改动的锁定母版，保留画布尺寸和全部金色边框：
顶部空白标题框；一个上部大内容框；两个并排中内容框；两个下部横内容框；底部空白页脚框。
不得移动、缩放、合并或重画边框。

为《标题》生成无文字水墨工笔底图。
大框右侧：<主意境>。
左中框右下：<小景一>。
右中框右侧：<小景二>。
第一横框右侧：<小景三>。
第二横框右侧：<小景四>。

五框全部有景且互不重复，每框左侧至少 55% 浅米白留白。
标题框和页脚框 100% 空白。
禁止任何文字、字母、数字、印章、题字、牌匾字符和水印。
插画不得压线、越框或遮挡边框。
```

## 八、AI 临时文件规则

1. imagegen 会先生成到 `~/.codex/generated_images/<会话编号>/exec-*.png`，这是工具初始行为，不代表正式存储位置。
2. 每次调用完成后必须立即将本项目对应文件复制到：
   `<当前临时目录>/图片生成中间文件/<批次>/NNN_标题_第NN次_<原exec编号>.png`。
3. 在完成复制和项目副本解码检查前，不得删除 `.codex` 原文件。
4. 默认保留 `.codex` 原文件；只有用户明确要求清理且已核对项目副本、哈希和文件归属时，才允许删除对应原文件。
5. 只能处理能够通过当前调用结果明确归属本项目的文件；禁止按时间模糊删除其他任务文件。
6. 批次结束后：
   - 正式采用稿进入 `<当前项目>/底图/`；
   - 达到三次上限的失败稿进入 `<当前临时目录>/失败废稿/底图草稿/`；
   - 已有正式稿且无复核价值的重复临时稿，可在映射清单确认后清理；
   - 有比较价值但不是当前正式底图的历史通过稿可进入 `<当前临时目录>/历史通过稿/<批次>/`。
7. `<当前临时目录>/图片生成中间文件` 必须按批次管理，不得长期把所有任务文件平铺在同一级。

## 九、逐张检测清单

### 9.1 无文字检查

- 标题框无插画、无文字、无符号。
- 页脚框无插画、无文字、无符号。
- 内容框、旗帜、牌匾、器物、建筑均无伪文字。

### 9.2 布局检查

- 一个大框、两个并排中框、两个横框全部存在。
- 五个内容框逐框有景。
- 插画集中在右侧，左侧文字安全区连续、明亮、无高对比干扰。
- 插画不重复、不呈矩形贴片、不产生突兀边缘。

### 9.3 几何检查

- 使用 `validate_locked_frame_geometry` 检查主卡片、双栏、横框与页脚框。
- 任一边框下移、上移、变宽、变窄、缺失、变形或出现重复横线，均判定失败。
- 自动框线检测通过后仍必须查看整图；检测通过不能覆盖肉眼发现的重复线、框内假边框或插画越区。

### 9.4 文件检查

- 图片可以重新解码。
- 色彩模式和尺寸符合批次标准。
- 文件名采用 `NNN_标题.png`。
- 编号无缺失、无重复，标题与核定清单一致。

## 十、修正与重试

1. 仅标题侵入、单栏缺图或局部主体重复时，优先对现有图做局部编辑。
2. 主卡片高度、双栏结构、横框位置或多个边框漂移时，必须放弃局部编辑，从锁定母版重新生成。
3. 每次修正后必须重新执行无文字、栏目完整性、框线、文字安全区和整图检查。
4. 同一首最多自动尝试三次。
5. 第三次仍失败时，保存三次草稿，写入失败记录，然后继续下一首，禁止阻塞整个批次。
6. 人工修复后必须重新运行完整检测；成功后在失败记录中标为“已修复项目（历史）”。

## 十一、正式底图准入条件

只有同时满足以下条件，图片才能进入 `<当前项目>/底图/`：

1. 无任何文字或伪文字。
2. 标题框和页脚框完全空白。
3. 五个内容框全部有不同插画。
4. 左侧排字安全区满足要求。
5. 锁定框线检测通过。
6. 原始分辨率整图检查通过。
7. 编号、标题、文件名和路径正确。

## 十二、批次结束检查

1. 按核定清单核对全部编号和标题。
2. 检查正式底图无缺号、无重复编号。
3. 检查失败记录中的未解决数量与正式目录缺失数量一致。
4. 检查 `.codex/generated_images` 中没有遗留本批次已迁移文件。
5. 检查 `<当前临时目录>/图片生成中间文件` 按批次归档，没有不明来源文件。
6. 输出通过数量、失败数量、临时目录、正式目录和失败记录路径。

## 十三、连续蒙学经典系列底图补充

1. 《三字经》等连续经典不要求每页生成独立底图；采用“封面1张＋主题系列A/B变体”的方式控制风格漂移。
2. 《三字经》正式策略为6个主题、每主题2张，共12张正文底图，加封面1张，合计13张。
3. 竖版正文安全区约为`x=80–710、y=300–920`；插画、建筑和深色植物不得侵入。
4. 同一主题的A/B底图应保持统一纸张、框线、色彩和人物画风，但场景与构图必须有可辨识变化。
5. 具体页序、文字坐标、对象数量、重试和打包要求按`RUL_三字经教学PPT批量生成工作流程规则.md`执行。
