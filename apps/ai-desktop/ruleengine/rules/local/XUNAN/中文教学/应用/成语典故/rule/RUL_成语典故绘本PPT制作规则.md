## 一、规则定位

本规则用于制作面向小学生的成语典故绘本 PPT，适用于《杯弓蛇影》《一箭双雕》《胸有成竹》等具有可靠历史典故的成语。

制作目标不是把“成语、释义和例句”机械地放进模板，而是让孩子通过连续绘本画面理解人物、事件和因果关系，并在看图后能够联想到成语、说出故事、理解含义、迁移运用。

本规则以已确认的《杯弓蛇影》样例为结构基准，以用户确认的绘本故事页截图为文字排版定稿依据。其他成语必须沿用统一的视觉语言和教学结构，但不得照搬《杯弓蛇影》的具体人物、场景、动作、道具或故事文字。

本规则是成语典故绘本PPT任务的专项正式执行依据。命中该任务后，必须与稳定逻辑 ID `HORIZONTAL_TEACHING_PPT_RULES` 共同加载；专项参数与横版通用参数冲突时，以本规则为准。没有可靠典故的普通成语不得误用本规则，应改按生活情境成语教学规则处理。

## 二、核心制作原则

1. **先核定典故，再创作绘本。**有可靠历史典故的成语，应核定人物、时代、起因、转折、结果及成语含义；没有固定典故的成语，只能设计帮助理解词义的生活情境，不得虚构历史出处。
2. **图片承担讲故事和解释文字的功能。**每页插画必须直接呈现该页的关键人物、动作、物品和因果关系，不能使用无关风景、通用人物或抽象装饰代替。
3. **绘本插画铺满全页。**图片按最终 16:9 画布比例独立生成，不使用正方形图片放大裁切，不使用六宫格或九宫格拆图，不把主画面缩成小图框。
4. **文字叠加在绘本画面上。**故事页采用“全页绘本插画＋悬浮文字卡”，插画为视觉主体，文字卡只承担清晰阅读，不遮挡关键情节。
5. **故事页数由情节决定。**不得把所有成语固定压缩成两页或三页。人物、起因、误会或行动、转折、真相与结果应按自然叙事节点分页。
6. **儿童能够看懂，也愿意读。**故事语言通俗、生动、句子短而完整；不堆砌书面词，不用成人化说教，不把释义重复写成故事。
7. **所有正式插画重新生成。**原教材图片、参考图或旧 PPT 图片只用于核定内容与构图方向，不直接嵌入新课件；同一成语各叙事节点原则上使用独立插画。

## 三、单个成语的标准教学结构

### 1. 诵读正音

- 展示成语及规范拼音。
- 每个拼音音节位于对应汉字正上方，拼音、汉字分别使用独立可编辑对象并逐字对齐。
- 标调必须正确；多音字、轻声和变调按核定读音处理。

### 2. 观图入境

- 使用一张能够直接表现成语核心含义的全页主视觉。
- 画面必须包含决定词义的关键人物、动作和物品。
- 例如“一箭双雕”应画出一人一箭同时射中两只大雕的关键动作，而不是只画人物持弓或两只鸟。
- 页面只保留成语、拼音和一句简短观察提示，不提前堆入长故事或完整释义。

### 3. 典故寻源

- 按自然叙事节点连续讲述故事，每个节点一页、每页一个核心事件。
- 每页配置独立绘本插画，画面与当页文字一一对应。
- 完整典故通常可拆为“人物与场景—事情发生—矛盾或误会—寻找原因—真相或结果”，但实际页数由故事决定。
- 《杯弓蛇影》样例采用四个节点：宴席出现怪影、朋友因恐惧生病、乐广找到原因、再次验证后真相大白。其他成语只继承这种叙事逻辑，不照搬四页数量。

### 4. 释义明理

- 先用一句话解释字面意思，再用儿童能够理解的语言说明现在常用的比喻义。
- 释义必须与典故形成因果闭环，不能只写抽象词典解释。

### 5. 学以致用

- 至少包含一个贴近儿童生活的例句或小场景。
- 场景优先来自学校、家庭、同伴交往、旅行或日常观察。
- 例句必须真正符合成语的使用条件，不能只把成语生硬塞进句子。
- 可增加一个“说一说”问题，引导孩子联系自己的经历。

### 6. 启智润心

- 从故事中提炼一条具体、可行动的启示。
- 表达要温和、简洁，避免空泛说教。
- 启示应回答“遇到类似事情时可以怎样做”，例如先观察、再求证，而不是只写“我们要做一个好孩子”。

## 四、画布与绘本插画规范

### 4.1 画布

- PPT 比例：16:9。
- 标准底图尺寸：1672×941 像素；允许 1672×940，但整套必须统一。
- 图片必须按横版画面一次生成，禁止生成正方形后强行拉伸、放大或裁切。
- 图片铺满整页，不留无意义白边。

### 4.2 绘本风格

- 采用精致、温暖、具有叙事感的国风儿童绘本风格。
- 历史典故中的服饰、建筑、器物和生活场景应符合故事时代的大体特征。
- 人物表情和动作要清楚，儿童一眼能够判断“发生了什么”。
- 画面色彩可以丰富，但不能过度艳丽、过度卡通或像游戏海报。
- 正式插画不得包含汉字、拼音、数字、印章、水印、牌匾文字、书册伪文字或其他可见文字。

### 4.3 构图预留

- 生成图片前先确定文字卡在左侧还是右侧，再在提示词中明确保留相应的低对比安全区。
- 文字安全区的最终视觉必须严格以用户确认参考图为准：呈现完整圆角、柔和浅淡的水彩晕染边界。边缘可有近似双层笔触，但两层只能若隐若现，不得表现为两条分离、清晰、等粗的白线；粗细和深浅略有变化，圆角自然，边缘与水彩纸纹理融合。
- 插画底图中的水彩留白框不设置、推断或描述任何透明度百分比，也不得以任何百分比进行近似换算。框内亮度、底色、背景显隐程度、边缘晕染范围和笔触强弱，全部按用户确认参考图的实际画面逐项对照；禁止用数值替代视觉标准。
- 框内应保持参考图所示的浅暖乳白水彩质感：整体明亮、柔和、低对比，边缘自然融入水彩纸纹理；禁止硬质数字描边、PowerPoint形状式均匀线框和突兀的纯白数字面板。
- 正式PPT另行叠加独立白色圆角文字卡，PowerPoint对象属性透明度统一为40%。该40%只约束PPT形状属性，不用于描述或验收插画底图中的水彩留白框。若PPT对象参数正确但最终观感偏离确认参考图，仍需调整底图安全区、文字卡尺寸或排版后重新渲染。
- 主要人物、关键动作和决定故事因果的物品应集中在文字卡之外。
- 人物头部、手势、衣袖、脚部、弓箭、酒杯、动物等关键主体必须完整入镜。
- 文字卡可以轻微覆盖次要背景，但不得遮挡故事证据。

### 4.4 通用插画提示词骨架

> 16:9 横版国风儿童绘本插画，画面表现【成语】故事中的【当前叙事节点】。人物为【人物身份与年龄】，正在【关键动作】，画面必须清楚出现【关键物品及因果关系】。构图把主要人物和关键动作安排在【右侧／左侧】，另一侧保留可放文字卡的安全区；安全区严格复现用户确认样图的实际观感：完整柔和的圆角水彩晕染边界、若隐若现且不规则的双层浅色笔触、浅暖乳白且明亮柔和的框内质感，边缘自然融入水彩纸纹理。不要为插画留白框设置、推断或描述透明度百分比；禁止纯白数字面板、硬质数字描边和PowerPoint形状式均匀线框。精致手绘质感，人物表情自然，故事性强，适合小学生，无任何文字、拼音、数字、印章、水印、牌匾字或伪文字，主体完整，不裁切头脚和关键物品，原生 1672×941 比例。

每页必须把方括号内容替换为当前成语的真实人物、动作和物品，禁止只换成语名称而保留通用场景。

## 五、故事页定稿版式

本节为后续所有成语故事页的强制优先版式，必须严格参照用户确认截图。

### 5.1 页面关系

- 全页插画铺满 16:9 画布。
- 文字卡放在插画预留安全区内，优先使用左侧竖向圆角卡；若故事关键动作在左侧，可镜像到右侧。
- 文字卡与插画必须形成一个完整画面，不能出现图片和文字彼此分离的“两块拼版”感。
- 页码置于右上角，不压住人物面部或关键物品。

### 5.2 40%透明文字卡

- 文字卡使用白色纯色填充。
- PowerPoint“设置形状格式→填充→透明度”统一设为 **40%**。
- 这里的“40%”指 PowerPoint 显示的透明度，即白色卡片保留 60% 不透明度；不能误设为只保留 40% 不透明度。
- 对应 OOXML 参数应为 `a:alpha val="60000"`；不得继续使用《杯弓蛇影》第二版中的 `90000`，因为 `90000` 对应的是 10% 透明度。
- 文字本身保持 100% 不透明，不对文字、拼音或页码应用透明度。
- 圆角卡不使用明显边框和重阴影；只要在深浅背景上都能保证文字清楚即可。
- 实际渲染后必须能透过文字卡看见底图的墙面、光线或环境色；如果底图安全区已被画成实心白块，或叠加后背景完全不可见，即使对象参数显示40%也判定为不合格。

### 5.3 1672×941参考位置

以下坐标来自用户确认截图的视觉比例，用作新页起点；遇到主体位置变化时可以左右镜像，但不得破坏层级关系。

| 对象 | 参考位置或范围 |
| --- | --- |
| 左侧文字卡 | `x≈80，y≈95，w≈630，h≈730` |
| 卡片内部左边界 | `x≈126` |
| 栏目标签 | `y≈135` |
| 页面故事标题 | `y≈180–225` |
| 第一段正文起点 | `y≈280` |
| 页码 | 距右约35–45像素，距上约30–40像素 |

坐标仅用于建立相同的视觉骨架。最终以人物不被遮挡、文字清晰、段落重心与截图一致为准。

### 5.4 文字层级

- 栏目标签：如“典故寻源·04”，使用暖红或赭红色，小号加粗。
- 故事标题：使用深青黑色，单行优先，明显大于正文，如“再看一次，真相大白”。
- 正文：使用深青黑色，字重适中，避免过细；同一套课件统一字体。
- 页码：白色或浅色，小号加粗，保证在背景上清楚。
- 标题和正文之间必须有清楚的呼吸空间，不能让正文贴近标题。

### 5.5 段落与断行

1. 每个语义段落独立排版，段落之间留出明显段间距；不能把整页故事压成一大块文字。
2. 每段首行缩进两个全角汉字位，缩进量为“2×正文字号”；续行回到正文框左边界。
3. 正文统一采用 **1.5倍行距**。
4. 严格按自然句式断行，优先在逗号、句号或完整语义短语后换行。
5. 不得把一个词、数量短语或紧密关联的主谓结构拆到两行。
6. 句号、逗号、问号、引号等标点不得单独落在一行。
7. 引号内容尽量保持完整；如必须换行，应避免只留下前引号、后引号或一个短词。
8. 一个自然段建议为2至4行；段落过长时应精简儿童表达或调整叙事节点，不能无限缩小字号。
9. 已有用户定稿截图时，截图中的卡片宽度、文字起点、段落位置和换行节奏优先于旧模板参数。
10. 首行缩进、续行起点和1.5倍行距必须通过实际渲染图检查，不能只看PPT对象属性。

### 5.6 截图所示的排版节奏

以“再看一次，真相大白”页为例，正文应形成三个清楚的故事段落：

- 第一段：乐广请朋友回到原座位，并再次倒酒。
- 第二段：朋友再次看见蛇影，乐广用墙上的弓和移动酒杯帮助他观察。
- 第三段：朋友明白杯中没有蛇，恐惧消失，身体很快恢复。

这三个段落分别承担“再次验证—揭示原因—消除误会”的作用。其他成语也应按情节作用分段，不得机械复制三段数量。

## 六、封面与成语首页规范

- 采用“全页关键情节插画＋半透明标题卡”或“全页关键情节插画＋大字叠加”的统一构图。
- 图片必须让孩子在未读释义前就能观察到成语的关键关系。
- 成语四字或固定字数词语按字位整齐排列。
- 拼音音节逐字放在对应汉字正上方，音节中心与汉字中心一致。
- 首页只设置一句简短观察问题，例如“酒杯里真的有蛇吗？”，不写长故事。
- 首页标题卡若采用白色悬浮卡，也统一使用PowerPoint透明度40%。

## 七、释义、运用与启示页规范

- 延续全页绘本插画和40%透明白色文字卡，不另起与故事页割裂的白底信息页。
- 栏目按“释义明理—学以致用—启智润心”从上到下组织。
- 每个栏目只承担一个教学任务，正文按语义分段。
- 释义先字面、后比喻义；例句贴近儿童生活；启示给出具体行动。
- 拼音与成语仍采用逐字对齐方式。
- 内容较多时优先精炼重复表达、优化卡片高度和段距；除非教学结构确实需要，不随意拆页，也不缩到儿童难以阅读的字号。

## 八、故事文字编写规则

### 8.1 写作顺序

1. 列出核定事实：人物、时代、地点、关键物品、起因、转折、结果。
2. 把事实拆成自然叙事节点。
3. 为每个节点写一句“本页要让孩子看懂什么”。
4. 先写儿童故事文字，再为本页设计插画。
5. 检查图片是否完整解释文字，文字是否又能准确描述图片。

### 8.2 儿童表达

- 一句话尽量只表达一个主要动作或变化。
- 使用具体动作词，如“端起、看见、指着、挪动、射中”，少用抽象词。
- 可以保留少量对话，帮助儿童理解人物心情，但不得编造改变典故因果的台词。
- 对难懂的古代器物，可在故事中用简单语言解释，不堆入括号注释。
- 保留悬念与转折，让孩子能够预测“接下来会发生什么”。

### 8.3 事实边界

- 可靠典故优先参考权威成语词典、教材或古籍出处。
- 不确定的人名、年代、地点和细节不得写成确定事实。
- 为了儿童理解可以简化句式，但不能改变谁做了什么、为什么发生、最后怎样的核心关系。

## 九、批量制作工作流程

### 第一步：输入盘点

- 建立成语清单，核对成语、拼音、年级、出处、故事、释义、例句和启示。
- 识别每个成语属于“可靠历史典故”还是“词义生活情境”。
- 标记缺失、冲突或需要核定的内容，不能带着事实缺口直接生成图片。

### 第二步：内容核定

- 校对拼音、人物和事件因果。
- 将原始长故事改写为儿童可理解版本。
- 为每个成语建立“叙事节点表”，确定页数和每页核心事件。

### 第三步：分镜设计

每个节点至少记录：

- 页面栏目与故事标题；
- 本页儿童故事文字；
- 主要人物、动作、表情和关键物品；
- 文字卡位置；
- 图片必须解释的因果关系；
- 不得出现的错误内容。

### 第四步：插画生成

- 按1672×941横版比例逐页生成原创插画。
- 每页使用与本页分镜完全对应的提示词。
- 生成后先检查人物、动作、物品、时代环境和安全区，再进入PPT排版。
- 失败图片单独重试，不因一页失败而阻塞其他成语。

### 第五步：PPT排版

- 插画铺满全页。
- 新增可编辑文字对象，不把文字烘焙进图片。
- 文字卡设为白色、PowerPoint透明度40%。
- 按截图骨架放置栏目、标题和正文。
- 每段首行缩进两字、续行回左、1.5倍行距，并通过手动换行控制自然句式。
- 拼音逐字置于汉字正上方。

### 第六步：链接与导航

- 单个样例可以只保留连续页码。
- 大型成语课件采用“总目录PPT＋分册PPT”；目录条目直达成语首页。
- 每个成语教学页提供返回本册目录、返回总目录、上一成语和下一成语的导航闭环。
- 导航按钮不得遮挡插画关键内容，链接必须在实际PowerPoint中抽查。

### 第七步：逐页验收

- 执行结构、溢出、媒体、链接和ZIP完整性检查。
- 渲染全部页面，并逐页查看原始尺寸图片。
- 联系表只用于检查整套节奏，不能代替逐页检查。
- 修正后重新渲染，直到结构与视觉检查均通过。

## 十、验收清单

### 10.1 内容

- [ ] 成语、拼音、人物、出处与因果关系已经核定。
- [ ] 有典故的成语讲清起因、经过、转折和结果。
- [ ] 没有固定典故的成语未被虚构成历史故事。
- [ ] 故事、释义、例句和启示互相一致。
- [ ] 文字适合儿童理解，没有成人化、空泛或重复表达。

### 10.2 图片

- [ ] 每页为独立生成的16:9横版绘本插画。
- [ ] 图片铺满页面，没有正方形放大或关键主体被裁切。
- [ ] 图片准确呈现本页文字中的人物、动作、物品和因果关系。
- [ ] 图片中没有文字、拼音、数字、水印、印章或伪文字。
- [ ] 文字卡没有遮挡关键人物、表情、手势或物品。
- [ ] 最终PPT未直接复用禁止使用的原图片。

### 10.3 文字卡与透明度

- [ ] 白色文字卡在PowerPoint中显示“透明度40%”。
- [ ] OOXML抽查值为`a:alpha val="60000"`，不存在误用`90000`。
- [ ] 文字、拼音和页码保持100%不透明。
- [ ] 深色与浅色背景上都能清楚阅读正文。

### 10.4 排版

- [ ] 栏目标签、故事标题、正文和页码层级与确认截图一致。
- [ ] 每段首行缩进两个汉字，续行回到正文左边界。
- [ ] 正文为1.5倍行距，段落之间有清楚停顿。
- [ ] 换行符合自然句式，没有孤立标点、破碎词组或突兀单字行。
- [ ] 标题不换行，正文没有溢出、压线或落入不可读深色区域。
- [ ] 拼音逐字位于对应汉字正上方并对齐。

### 10.5 整套一致性

- [ ] 不同成语沿用同一画布、色彩、字体层级、40%透明卡和页面功能结构。
- [ ] 每个成语保留自己的真实人物、场景、动作和关键物品，没有机械套图。
- [ ] 故事页数由内容决定，没有为了统一页数而删减或填充。
- [ ] 目录、返回、上一条和下一条链接形成完整闭环。
- [ ] 已逐页查看原始尺寸渲染图，并记录发现的问题与修正结果。

## 十一、样例继承与禁止事项

### 必须继承

- 《杯弓蛇影》样例的“看图猜成语—连续绘本故事—释义运用启示”学习顺序。
- 全页绘本插画与悬浮文字卡的整体关系。
- 逐字拼音、儿童故事语言和自然叙事节点。
- 用户截图确认的栏目、标题、正文、分段与断行节奏。
- 本规则核定的40%透明文字卡标准。

### 禁止照搬

- 不照搬《杯弓蛇影》的四页故事数量。
- 不照搬宴席、酒杯、弓影、乐广等具体人物和场景。
- 不把同一张图或同一组人物姿势机械复用到其他成语。
- 不使用固定字数硬填卡片，不用无关插图装饰空白。
- 不把词典释义冒充绘本故事，也不把一段长文字平均切成数页。

## 十三、执行口径

后续制作任何成语典故绘本PPT时，必须先读取本规则，再加载稳定逻辑 ID `HORIZONTAL_TEACHING_PPT_RULES`。两者发生参数差异时：

- 成语国学绘本的文字卡透明度以本规则确认的 **40%** 为准；
- 通用的图片完整性、原创素材、可编辑文字、逐页渲染和检查要求继续执行；
- 用户为某个具体成语提供新的定稿截图时，该截图只覆盖对应项目的视觉参数，不自动改变其他成语，除非用户明确要求提升为通用标准。
