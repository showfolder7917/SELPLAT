requirement.1 = 成语分级是面向儿童认知难度的编辑分级，不冒充教材官方篇目表。
requirement.2 = 一、二年级优先选择人物少、因果直接、情节清楚的寓言典故。
requirement.3 = 三、四年级可以加入讽喻、误会、品格和学习主题。
requirement.4 = 五、六年级可以加入历史人物、谋略和多阶段转折，但必须弱化战争伤害和惊吓画面。
requirement.5 = 每个典故先写儿童版故事梗概，再拆分“起因—发展—转折—结果”；图片数量必须由实际情节决定，不为凑数重复近似画面。
requirement.6 = 简单典故默认3幅，人物、地点或转折较多的历史典故可用4幅；确有需要时允许增加，但必须在生成前写入分镜规划。
requirement.7 = 不得混用同名异说；人物、时代、核心事件和成语寓意必须与选定典故版本一致。
requirement.8 = 正式图片固定为1672×941像素，横版约16:9，与当前古诗正式横版图片一致。
requirement.9 = 统一使用明亮、温暖、细腻的中国风儿童水彩绘本风格，结合工笔轮廓、宣纸肌理和自然光。
requirement.10 = 一、二年级人物比例更可爱、表情更明确、动作更易读；三至六年级逐步增加历史环境和服饰细节，但不得变成阴暗成人古画。
requirement.11 = 同一典故内锁定主要人物的年龄、脸型、发式、服装颜色、配饰和体态；相邻图片只改变动作、机位和场景进展。
requirement.12 = 不同典故不得机械复用同一人物脸、同一房屋、同一树木或同一构图。
requirement.13 = 每幅图只表现一个清楚的主要动作或情节节点。
requirement.14 = 主体必须完整可辨，手、脚、动物四肢、关键道具和人物互动不得被无意裁断。
requirement.15 = 镜头在全景、中景和近景之间有节奏变化；禁止连续三幅都使用同一正面站姿。
requirement.16 = 场景必须符合故事时代和生活环境，不出现现代服装、电器、塑料制品、现代道路或现代建筑。
requirement.17 = 历史战争典故表现调度、行军、旗阵和人物决断，不表现血腥、尸体、重伤或恐怖特写。
requirement.18 = 图片四边必须完整覆盖，不留黑边、白边、拼贴接缝或假相框。
requirement.19 = 画面不为后续文字排版强制留出大块空白；构图以完整绘本画面和情节可读性为准。
requirement.20 = 所有正式图片必须无汉字、拼音、字母、数字、标点、印章、书法、牌匾字、旗帜字、书册字、页码、品牌和水印。
requirement.21 = 店铺、城门、卷轴、竹简、酒坛、旗帜和墙面不得生成伪文字或似字纹样。
requirement.22 = 如模型生成无法辨识的伪文字，该图判定失败，最多定向修正三次。
requirement.23 = 主要人物数量、年龄和身份；
requirement.24 = 脸型、发式、胡须和表情基调；
requirement.25 = 上衣、下裳、腰带、鞋履和主色；
requirement.26 = 关键动物的品种、毛色和体型；
requirement.27 = 关键道具的形状、材质和颜色；
requirement.28 = 朝代环境、季节、天气和统一色调。
requirement.29 = 年级目录使用“一年级”至“六年级”。
requirement.30 = 每个典故一个同名文件夹。
requirement.31 = 图片以两位连续序号开头，后接简短情节名；不得出现缺号、重号或无意义文件名。
requirement.32 = imagegen原始结果必须复制到对应项目文件夹；不得只保存在全局生成缓存。
requirement.33 = 不覆盖已通过图片；重新生成时先保留旧稿并使用版本后缀，确认新稿通过后再确定正式文件。
requirement.34 = 尺寸为1672×941，能够正常解码。
requirement.35 = 当前分镜的主要动作一眼可辨。
requirement.36 = 无文字、伪文字、数字、印章和水印。
requirement.37 = 主体完整，人物肢体和关键道具关系自然。
requirement.38 = 同一典故人物外观、服装、道具和画风连续。
requirement.39 = 历史环境合理，没有现代物件或时代混搭。
requirement.40 = 儿童观看安全，无血腥、恐怖和过度阴暗画面。
requirement.41 = 色彩、透视、光线和画面重心自然，不存在一眼可见的错位、重复主体、畸形手脚或不合理比例。
requirement.42 = 单张图片最多自动尝试三次。
requirement.43 = 人物身份或服装漂移时，重新强调角色不变量；只修当前图片，不改写已通过图片。
requirement.44 = 伪文字、畸形肢体、主体重复、时代错误或关键动作错误均必须重试。
requirement.45 = 三次仍失败时保留最后稿并记录失败原因，然后继续后续典故，禁止阻塞整批。
requirement.46 = 批次结束后核对计划图片数、正式图片数和失败数，三者必须能够对应。
requirement.47 = PPT继续使用1672×941横版比例，图片等比覆盖全页。
requirement.48 = 每页先识别人物、动物、关键道具和主要动作范围，再选择左侧、右侧、顶部或底部的空闲区域放置文字；禁止固定套用同一坐标。
requirement.49 = 文字不得压住人物脸部、肢体、动物、关键道具或故事动作；即使文本框未越界，只要遮挡叙事主体仍判定失败。
requirement.50 = 文字承托卡片使用大圆角、宽松内边距和克制描边；透明度固定为40%，即不透明度60%。
requirement.51 = 卡片应形成一至两个完整信息区，禁止拆成大量狭窄、零碎的小框。
requirement.52 = 卡片宽高根据实际文字量调整，并与画面视觉重心保持平衡；禁止大段空白卡片、文字贴边、卡片过宽或压住半幅主场景。
requirement.53 = 相邻页面标题、正文、色彩和卡片圆角保持统一，但卡片位置必须随各页插图主体动态变化。
requirement.54 = 每页实际渲染后检查文字可读性、主体遮挡、40%透明度、圆角比例和整体视觉平衡；一眼可见的不合理布局不得交付。
