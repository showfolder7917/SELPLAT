# AI Desktop 字体可读性视觉验收

## 验收范围

- 用户目标：开发版界面的字体至少达到参考图的可读性，优先接近 VS Code 桌面 IDE 的字体密度。
- 参考图（主要）：`OPTION/temp/ai-desktop/typography-qa/reference-vscode.png`，2945 × 1285。
- 参考图（辅助）：`OPTION/temp/ai-desktop/typography-qa/reference-codex.png`，1754 × 940。
- 实现截图：`OPTION/temp/ai-desktop/typography-qa/implementation-pass-1.png`，1223 × 768。
- 验收状态：简体中文、深色主题、SELPLAT 工作区展开、只读模式、Codex harness 已连接。

## 对照检查

### 整体视图

- 左侧资源管理器、工作区折叠面板、文件行和新建任务按钮均达到桌面 IDE 可读密度。
- 中央欢迎文案、输入框、标签页和底部状态文字层级清楚，没有文字截断、重叠或溢出。
- 右侧 Context 标题、字段名和字段值可直接阅读，字号层级与参考图一致。
- 原有布局、颜色、边框和交互结构保持不变，本轮只调整字体与相匹配的行高。

### 重点区域

- 关键导航、工作区树、控件、聊天正文和上下文值使用 13–15 CSS px。
- 工作区与文件行高提升到 31–35 px，点击区域和文字垂直居中正常。
- 设置面板的标题、标签、选择框与账户信息同步放大，不再使用 10–11 px 承载关键内容。
- 图标继续使用现有 Fluent 图标库；本次没有需要替换或缩放的位图素材。
