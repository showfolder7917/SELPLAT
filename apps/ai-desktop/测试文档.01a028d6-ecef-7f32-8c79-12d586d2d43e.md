# AI Desktop 协同模式测试文档

## 本轮目标

- 单会话模式保持原有线程、托管阶段和消息队列行为。
- 协同模式稳定列出韩立及 11 名默认工作人物，并支持非受保护人物增删改查。
- 韩立确认的任务持久排队；空闲执行人取得新 Codex 和独立 Git worktree，异人审核最多三次明确驳回后进入任务执行。
- 执行人与审核员完成临界点先持久化结果，再销毁临时线程和进程；应用重开后显示恢复入口。
- 独立完成任务进入冻结集成代，不等待无依赖的未完成任务；详细耗时和等待归因只进入日志。
- 审核正文和机器结论分开处理：兼容结构化标签、旧标记与明确中文结论；缺少结论时由原审核员补取一次；每次尝试、原正文和失败原因持久化，格式问题不计为基础设施失败。
- 审核只判断客户最低必要需求；满足即通过，不用非必要优化扩大驳回范围；第三次明确驳回后完成最后一次必要修正并强制执行，不进入第四轮审核。
- 独立集成工作区自动复用锁文件一致的依赖或离线优先补齐；组合检查后清理临时依赖链接，候选分支与稳定集成分支不发生 Git 引用冲突。
- 恢复宋玉任务并通过真实组合检查，将刷新图标和“重新建立一个 Codex 会话”提示最终合入本地 `dev` 分支。
