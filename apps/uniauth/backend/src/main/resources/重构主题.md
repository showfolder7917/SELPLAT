应该拆成“通用控件 + 主题包”，不能继续把深色、浅色直接当成主题。现在这套目录实际上把“水晶科技、明暗模式、主题色”混在了一起，增加可爱风格后会越来越难维护。
建议把视觉体系分成四个独立维度：
维度	示例	职责
主题风格 Theme	水晶科技、可爱萌系、简约商务	决定材质、圆角、阴影、字体气质、装饰方式
明暗模式 Mode	深色、浅色、跟随系统	决定背景亮度和文字对比
强调配色 Accent	蓝、青、紫、绿、金、粉	只改变品牌色和交互色
用户覆盖 Override	透明度、间距、模糊、字号	个性化面板的临时调整


根节点建议改成：
<html
  data-sel-theme="crystal-tech"
  data-sel-mode="dark"
  data-sel-accent="stellar-blue"
  data-sel-density="comfortable"
>
这样：
crystal-tech + dark + blue：深色蓝色水晶科技
crystal-tech + light + pink：浅色粉色水晶科技
cute + light + pink：浅色粉色可爱风格
cute + dark + purple：深色紫色可爱风格

哪些必须通用
通用控件只负责：
DOM结构
表格、树、菜单和窗口行为
键盘操作与无障碍
拖动、缩放、滚动
响应式布局
加载、空状态、错误状态
消费统一语义令牌
例如通用组件只能写：
.selpanel-surface {
    color: var(--sel-text-primary);
    background: var(--sel-surface-panel);
    border: var(--sel-border-panel);
    border-radius: var(--sel-radius-panel);
    box-shadow: var(--sel-shadow-panel);
}
不能再写：
background: rgba(4, 18, 58, 0.8);
box-shadow: 0 0 16px #4a8bff;
border-image: url("水晶边框.webp");
当前组件CSS中仍有约400处直接色值或rgba()，说明水晶视觉还大量泄漏在通用控件中。尤其是：

哪些属于主题包
水晶科技主题负责：
水晶九宫格边框
深海玻璃底板
蓝紫发光
水晶光效动画
科技感背景
水晶鼠标
科技字体与字距默认值
可爱风格主题负责：
柔和实色或糖果渐变边框
更大的圆角
柔软阴影
圆润字体
可爱插画和背景
弹性较强的动效
星星、爱心、糖果等装饰
可爱主题不应该复制selPanel.js、selGrid.js或selWindow.js，只提供另一组令牌、素材和少量绘制覆盖。
统一令牌建议分三层
1. 基础令牌
--sel-color-brand;
--sel-color-neutral;
--sel-font-family;
--sel-radius-base;
--sel-shadow-strength;
--sel-motion-duration;
2. 语义令牌
--sel-surface-page;
--sel-surface-panel;
--sel-surface-control;
--sel-surface-popup;

--sel-text-primary;
--sel-text-secondary;
--sel-text-disabled;

--sel-border-default;
--sel-border-focus;

--sel-state-hover;
--sel-state-selected;
--sel-state-danger;
3. 组件令牌
--sel-panel-frame-image;
--sel-panel-frame-width;
--sel-panel-radius;
--sel-panel-shadow;

--sel-grid-row-background;
--sel-grid-row-hover;
--sel-grid-row-selected;

--sel-window-header-height;
--sel-menu-item-radius;
组件只读取第二、第三层，不直接读取主题原始RGB。
个性化设置也要改成注册驱动
当前 [selPersonalization.js](/Users/showfolder/Documents/workSpace/SELF/SELPLAT/apps/uniauth/backend/src/main/resources/static/sel/components/personalization/selPersonalization.js) 内部直接写死了：
深色、浅色两套皮肤
水晶边框地址
水晶主题色
配套背景
水晶预览颜色
以后它应该只读取主题注册表：
selThemeRegistry.register({
    id: "crystal-tech",
    name: "水晶科技",
    modes: ["dark", "light"],
    accents: ["blue", "cyan", "purple", "green", "gold", "pink"],
    defaults: {
        mode: "dark",
        accent: "blue",
        background: "deep-space"
    }
});
可爱主题再单独注册：
selThemeRegistry.register({
    id: "cute",
    name: "可爱萌系",
    modes: ["light", "dark"],
    accents: ["pink", "peach", "mint", "lavender"],
    defaults: {
        mode: "light",
        accent: "pink",
        background: "candy-cloud"
    }
});
个性化界面则调整为：
风格：水晶科技、可爱萌系
明暗：深色、浅色、跟随系统
配色：显示当前风格支持的色板
背景：优先显示当前风格配套背景
面板与文字：继续提供用户覆盖
