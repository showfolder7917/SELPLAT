# 文件统一读取规则

- memory 的启动链、规则、索引、Agent 定义、配置、任务文档和受检文件必须通过 `com/sp/selplat/core/文件读取器.py` 读取。
- 业务模块禁止直接使用 `open()`、`Path.read_text()`、`Path.read_bytes()` 或其他旁路读取受管文件。
- 文件读取前必须校验规范化路径、允许读取根、文件存在性、符号链接、大小上限、文件类型和字符编码。
- 第一版只解析 UTF-8 文本与 Markdown；Excel、Word、PDF 等文档类型必须在登记专用 Reader 后才能解析。
- 未支持类型、非法编码、路径逃逸、文件缺失或超限必须明确失败，禁止静默降级、猜测内容或返回空文本。
- Python 源文件使用中文业务文件名；类、函数、参数、变量、异常类和稳定标识使用英文。
