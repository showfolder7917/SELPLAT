# 照片上传规格转换执行文档

## 目标

将 `OPTION/照片` 中的两张原始照片制作成符合上传要求的 JPEG 文件，并保存到 `OPTION/1`。

## 输入

- `OPTION/照片/XUNAN.png`（1122×1402）
- `OPTION/照片/TONGXIAOFENG.png`（1122×1402）

## 输出约束

- 输出格式必须为 JPEG。
- 输出尺寸采用 480×640 像素，满足“不小于 480×640”的要求。
- 单个文件不得超过 5MB。
- 保持人物身份、五官、发型、服装和照片真实外观，不做生成式美化。
- 不覆盖输入原图；输出进入 `OPTION/1`。

## 执行步骤

1. 查看两张原图，确认人物位置和可用裁切范围。
2. 按 3:4 比例居中裁切，避免拉伸变形。
3. 缩放为 480×640 并转换为 JPEG。
4. 检查输出格式、像素尺寸、文件大小和可视结果。

## 回退

输出为新增文件；如结果不合格，只删除对应新增输出，原始照片保持不变。
