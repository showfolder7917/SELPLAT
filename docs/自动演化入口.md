## 实施调整（2026-08-26）

- 审批采用“统一治理投影 + 分域状态机”：演化方向、协作方案评审、Codex 命令授权可以统一检索，但不能互相冒充。
- 协作任务完成只进入“等待韩立验收”，不能直接宣布演化完成或自动开始下一轮。
- 韩立验收通过后才累计完成轮次；验收退回继续由南宫婉纠偏。
- 自动演化支持有限轮次和无限模式，同时支持节点纠偏上限、暂停、继续与停止。
- 有限专题达到轮次上限后暂停，等待韩立确认下一个演化方向。
- 不使用固定收益分、用户符合度分或次数阈值替代 AI 对证据、反例、风险和用户当前方向的综合判断。

## 专题确立与专题池原始档案（2026-08-26 修正）

- 自动演化不是从对话库直接“发现一个专题”。韩立必须按完整会话组综合南宫婉与 Codex 的对话原文，先形成需要问清的问题。
- 韩立是研讨发问方：每轮只向南宫婉提出一个有依据的问题，再根据南宫婉原回答决定继续追问、纠偏或确立演进专项。
- 韩立确立专项后通知南宫婉；南宫婉负责把专项登记到长期专题池，再通过专题池形成方案、拆解任务和分发执行。
- 专题池不是标题列表。每个专题保存来源会话不可变快照、韩立每轮原问题、南宫婉每轮原回答、韩立判断、专题确立、方案版本、审批、任务、命令、日志、测试、发布、重启、验收和纠偏的完整原记录。
- 原始档案只追加、不覆盖；页面的当前状态和摘要是原记录之上的派生视图。来源会话同时保留原 ID 引用和冻结快照，避免原库迁移后证据丢失。

```text
→ 韩立真实操作验收
→ 通过归档或继续纠偏
```
