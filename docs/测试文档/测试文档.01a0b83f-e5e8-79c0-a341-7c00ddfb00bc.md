# 当前专题技术卡点解除后的页面状态复验

## 变更与预期

- 在持久异常全部标记为 `resolved` 后，技术恢复状态保留问题次数和证据，但设为非活动；缺失或仍未解除的事件不得提前收口。
- 应用重启时，即使旧事件已从待处理队列退出，也要依据持久事件状态收口旧提示；页面不再显示“令狐老祖处理中／系统重试写入令狐交接”。
- 原提案最终验收仍以独立验收证据为准，不能因卡点解除而直接显示通过。
