# 韩立、南宫婉统一人物会话升级测试

## 测试目标

- 验证韩立与南宫婉通过同一人物会话契约、IPC 和 Renderer Hook 接入，并由 `personaId` 隔离各自会话。
- 验证人物完整原话只保存在统一会话表，专题演化 JSON 不再复制第二份会话正文。
- 验证用户与人物的完整回合仍可进入训练语料；人物内部交流不冒充用户语义资料。
- 验证专题群发言使用统一人物消息入口，并把消息引用与短预览回流既有专题档案。
- 验证升级后的设置、截图、托管、协作、专题工作台及真实 Electron 页面没有回归。
