MEMORIES 结构与阅读链路

这页不是过程文档，而是给人类快速看懂当前记忆库怎么分层、每层做什么、链路从哪里开始、重开会话后先读什么。

现在的结构

  • MEMORIES/ai/ 是 AI 侧正式结构根目录。
  • MEMORIES/ai/ 内部当前以三层正式目录为主：protocol、rule、code。
  • MEMORIES/human/ 保留为人类整理区，负责需求、偏好、经验、聊天记录和脚本整理。

链路开始端

  1. 重开会话后，先读 ./MEMORIES/ai/protocol/STARTER_PROTOCOL.md
  2. 只有需要更细规则时，再补读 rule/ 下的具体文件
开始端 = ./MEMORIES/ai/protocol/STARTER_PROTOCOL.md

目录总览

MEMORIES 根目录只放入口、总说明、映射文档、结构说明和架构图；真实内容主要分成 ai 和 human 两区。

ai

AI 正式结构根目录。用于承接启动规则、正式规则和 code 运行层，不保留主要给人类看的说明文档。

protocol/ 协议层。`STARTER_PROTOCOL.md` 是唯一最小启动入口；规则按需通过 `RULE_INDEX.md` 进入，不在启动链默认展开。
rule/ 正式规则层。当前以扁平规则文件为主，专项协议默认对应同主题规则文件。
code/ 运行与编码层。这里同时承接运行能力库入口，以及 Python、JS、Java 的专题协议/规则/经验所对应的代码运行目录。

human

人类整理区。先记录需求、偏好、经验、聊天记录和脚本，再决定哪些内容需要提升进 AI 侧正式结构。

RULE_INDEX.md Human 总索引，统一汇总需求、偏好、经验、聊天记录和脚本。
需求/ 需求文档与任务说明。
偏好/ 用户回答偏好与协作口径。
经验/ 人类复盘材料与历史错误经验。
聊天记录/ 原始聊天记录与完整对话归档。
脚本/ 可直接手动执行的脚本入口。

阅读链路

1
重开会话先读 protocol 先读 ai/protocol/STARTER_PROTOCOL.md，确认当前启动规则和最小读取链路。
2
按需读其他协议 从 ai/rule/RULE_INDEX.md 中按任务类型选择规则，不默认全量展开。
3
再从协议进入 rule 如果任务涉及执行口径、记忆写入、协作风格或提示词规范，再去读 ai/rule/ 下的具体规则。
4
最后按需进入 experience 如果需要更细的历史判断依据，优先回到同主题规则或代码上下文，不再保留独立经验目录。
5
按任务类型进入 code Code 层同时承接运行入口与专题编码入口；运行任务读 RUNTIME_ENTRY.md，专题任务按主题进入对应协议、规则、经验。

重开会话后先读什么

  1. ./MEMORIES/ai/protocol/STARTER_PROTOCOL.md
默认不再要求一上来全量展开多个规则文件，直接从单一启动入口进入。

AI 区边界

  • ai/ 只保留 AI 正式知识、运行层、规则和必要模板。
  • 主要给人类看的说明文档不再保留在 ai/。
  • ai/code/ 是当前唯一的 code 运行层目录，不再单独保留旧的运行层命名。

什么时候读 rule

  • 要确认回答风格、协作口径时：读 ai/protocol/USER.PROTOCOL.md
  • 要确认执行方式、索引同步、命令口径时：读 ai/rule/PROJECT_EXECUTION_RULES.md 与 ai/protocol/COMMAND.PROTOCOL.md
  • 要确认记忆文件改写边界时：读 ai/rule/MEMORY_FILE_EDIT_RULES.md
  • 要执行 GUI 或视频任务时：读 ai/rule/GUI_VIDEO_TASK_RULES.md
  • 要执行 Code 运行相关任务时：读 ai/protocol/CODE.PROTOCOL.md
规则层按协议同主题文件直接定位

什么时候读 experience

  • 当前结构已取消独立经验目录。
  • 已有经验判断应直接回到同主题规则、协议或代码上下文中处理。
  • 这类材料不再作为单独一层入口存在。
经验判断回收到规则层和代码上下文，不再通过独立 experience 目录定位

什么时候读 code

  • 运行任务：读 ai/code/RUNTIME_ENTRY.md
  • Python 主题：CODE_PYTHON_RULES.md / PYTHON_EXPERIENCE.md
  • JS 主题：CODE_JS_RULES.md / JS_EXPERIENCE.md
  • Java 主题：CODE_JAVA_RULES.md / JAVA_EXPERIENCE.md
统一入口：./MEMORIES/ai/code/RUNTIME_ENTRY.md

什么时候读 code 运行层

  • Code 运行任务优先走 ability，不直接走 skill
  • abilities/ 是 AI 可调用入口
  • skill/ 和 app/ 是内部依赖
  • registry/ 负责机器索引，执行约束已并入 CODE.PROTOCOL.md
统一入口：./MEMORIES/ai/code/RUNTIME_ENTRY.md

人类该看哪几个入口

  • 看目录导航：Home.md
  • 看可视化结构和阅读链路：当前这份 guid.htm
