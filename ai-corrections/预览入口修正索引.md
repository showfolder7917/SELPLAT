# 预览入口修正索引

本文件用于约束静态预览页、皮肤选择入口和主预览区结构发生变化后，AI 必须同步修正的文件范围。

## 1. 触发动作：调整主题预览入口布局

必须同步修正的文件：

- `shared/frontend/theme/glass-theme/index.html`
- `shared/frontend/theme/glass-theme/README.md`
- `shared/frontend/theme/README.md`
- 若架构文档中明确描述了旧预览方式，则同步更新对应架构文档

可选同步检查文件：

- 与当前入口页相关的皮肤说明文档
- 若 `ai-corrections` 当前文件中规则已不再覆盖最新入口模式，则同步更新本文件

需要避免的旧描述：

- 代码已经改成新布局，但文档仍按旧交互描述
- 入口页已从纵向改为双栏，但说明仍写“向下翻找主预览”

## 2. 触发动作：调整皮肤切换机制

必须同步修正的文件：

- 主题入口页 `index.html`
- 主题家族 `README.md`
- 若切换机制影响架构层说明，则同步更新相关架构文档

可选同步检查文件：

- 默认皮肤说明
- 分组说明或标签说明

需要避免的旧描述：

- 默认皮肤、切换方式或入口按钮模式已变，但 README 仍按旧方式描述

## 3. 触发动作：新增预览分组或皮肤分组

必须同步修正的文件：

- 主题入口页 `index.html`
- 主题家族 `README.md`
- 若 `shared/frontend/theme/README.md` 中有主题总览，也应同步更新

可选同步检查文件：

- 架构文档中对预览入口的描述
- 当前文件中的示例和约束说明

需要避免的旧描述：

- 皮肤已按深浅或业务分组，但入口说明仍表现为平铺或无分组

## 4. 触发动作：删除预览入口或重做预览方式

必须同步修正的文件：

- 对应预览入口文件
- 主题家族 `README.md`
- 主题总览 `README.md`
- 若架构文档仍描述旧预览实现，则同步修正

可选同步检查文件：

- 是否需要新增新的预览入口说明
- 是否要在 `ai-corrections/索引.md` 中补充新入口名称

需要避免的旧描述：

- 旧预览入口已删除，但文档和索引仍把它当成主入口
