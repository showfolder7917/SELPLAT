# ai-corrections

这里放给 AI 和自动化修改流程使用的修正索引文档。

定位：

- 记录某类结构变更发生后，必须同步修正哪些文件
- 帮助 AI 在新增、删除、重构时快速找到联动修改范围
- 约束 AI 不再沿用已经失效的旧描述

适用范围：

- 主题系统
- 模块系统
- 数据库工程
- 静态预览入口
- Java 代码规范与迁移规范

不适合放的内容：

- 业务功能说明
- 页面交互细节实现
- 普通开发教程
- 会话期临时执行记录

使用规则：

1. 当任务涉及新增、删除、重构时，应优先查看对应修正索引。
2. 当某类结构变更已形成稳定联动范围时，应补充或更新这里的索引文件。
3. 这里记录的是“同步修正范围”，不是替代架构文档或目录 README。
