# 数据库工程修正索引

本文件用于约束数据库能力被视为独立工程后，AI 在调整工程层与运行层时必须同步检查的文件范围。

## 1. 触发动作：新增数据库工程

必须同步修正的文件：

- 新数据库工程自身 `README.md`
- 新数据库工程自身 `manifest`
- 平台根 `README.md`
- `apps/README.md`
- 对应数据库架构文档

可选同步检查文件：

- `runtime/data` 下是否需要新增运行目录说明
- 是否需要补充数据库查询台或工具入口说明

需要避免的旧描述：

- 数据库工程已存在，但平台文档仍把数据库能力当成零散目录

## 2. 触发动作：调整 schema、seed、migration 分层

必须同步修正的文件：

- 数据库工程自身 `README.md`
- 若已有数据库架构文档，则同步更新目录结构说明
- 若修正索引规则已过时，则同步更新当前文件

可选同步检查文件：

- 初始化脚本说明
- 数据导入导出说明

需要避免的旧描述：

- 目录已重构，但文档仍按旧分层描述

## 3. 触发动作：调整运行数据库文件路径

必须同步修正的文件：

- 平台根 `README.md`
- 数据库工程自身 `README.md`
- 相关架构文档中对工程层和运行层边界的说明

可选同步检查文件：

- 启动脚本说明
- 测试或演示环境说明

需要避免的旧描述：

- 运行库文件已迁移，但文档仍指向旧路径

## 4. 触发动作：数据库工程改名

必须同步修正的文件：

- 工程自身 `manifest`
- 工程自身 `README.md`
- `apps/README.md`
- 平台根 `README.md`
- 相关架构文档

可选同步检查文件：

- 查询工具说明
- 脚本路径说明

需要避免的旧描述：

- 新旧工程名混用，导致 AI 后续继续按旧工程名执行
