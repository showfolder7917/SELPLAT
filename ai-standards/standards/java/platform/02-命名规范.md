# 命名规范

类命名：

- Controller 以 `Controller` 结尾
- Service 接口以 `Service` 结尾
- Service 实现以 `ServiceImpl` 结尾
- DAO 接口以 `Dao` 结尾
- 输入模型以 `In` 结尾
- 输出模型以 `Out` 结尾

方法命名：

- 查询类方法使用 `select`、`find`、`list`
- 新增类方法使用 `insert`、`save`
- 更新类方法使用 `update`
- 删除类方法使用 `delete`、`remove`

字段命名：

- Java 字段保持驼峰
- 数据库列保持下划线，由映射层统一转换
