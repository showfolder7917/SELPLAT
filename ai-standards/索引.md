# AI 规范总索引

本文件用于总览 `ai-standards` 目录下的当前工程规范与同步修正索引，帮助 AI 按任务类型定位生效标准和联动修改范围。

## 1. 主题系统

- `主题系统修正索引.md`
  适用：新增皮肤、删除皮肤、新增主题家族、删除主题家族、主题结构重构。

## 2. 模块系统

- `模块系统修正索引.md`
  适用：新增模块工程、删除模块工程、模块改名、宿主与模块装配关系调整。

## 3. 数据库工程

- `数据库工程修正索引.md`
  适用：新增数据库工程、调整 schema 或 migration 分层、调整运行数据库文件路径。

## 4. 预览入口

- `预览入口修正索引.md`
  适用：静态预览页结构调整、皮肤列表布局调整、切换机制变更、预览说明同步修正。

## 5. Java 规范

- `standards/java/README.md`
  适用：Java 通用编码规范、后端分层规范、迁移规范、样板基线说明。

## 6. 使用顺序建议

1. 先确认当前任务属于哪一类结构变更。
2. 再进入对应修正索引，查“必须同步修正的文件”。
3. 修改完成后，检查是否存在需要补充的新修正规则。
