# 主题系统修正索引

本文件用于约束主题系统发生结构变更后，AI 必须同步检查和修正的文件范围。

## 1. 触发动作：新增皮肤

必须同步修正的文件：

- `shared/frontend/theme/glass-theme/manifest/theme-family.json`
- `shared/frontend/theme/glass-theme/README.md`
- `shared/frontend/theme/README.md`
- `shared/frontend/theme/glass-theme/index.html`
- `docs/architecture/玻璃主题家族与皮肤分层架构蓝图_2026-06-09.md`

可选同步检查文件：

- 新皮肤自己的 `README.md`
- 新皮肤自己的 `preview/index.html`
- 若存在皮肤分组说明，则检查是否需要新增分组描述

需要避免的旧描述：

- 皮肤数量仍写成旧数量
- 入口页仍按旧皮肤集合描述
- 架构文档仍只举旧皮肤示例

## 2. 触发动作：删除皮肤

必须同步修正的文件：

- `shared/frontend/theme/glass-theme/manifest/theme-family.json`
- `shared/frontend/theme/glass-theme/index.html`
- `shared/frontend/theme/glass-theme/README.md`
- `shared/frontend/theme/README.md`
- 若架构文档中明确提到该皮肤，则同步更新 `docs/architecture/玻璃主题家族与皮肤分层架构蓝图_2026-06-09.md`

可选同步检查文件：

- 皮肤目录是否已完全移除
- 是否仍保留指向该皮肤的预览路径

需要避免的旧描述：

- manifest 已删除，但 README 或 index 仍保留旧皮肤
- 预览入口仍可以切换到已删除皮肤

## 3. 触发动作：新增主题家族

必须同步修正的文件：

- `shared/frontend/theme/README.md`
- 新主题家族自身 `README.md`
- 新主题家族自身 `manifest`
- `docs/architecture` 下该主题家族对应的架构文档
- `ai-standards/索引.md` 中如需补充主题家族层面的导航说明则同步补充

可选同步检查文件：

- 主题根目录是否需要新增统一入口页
- 是否需要补充新主题家族的预览入口修正规则

需要避免的旧描述：

- 平台说明仍表现为只有 `glass-theme`
- 新主题家族已存在，但没有配套架构说明

## 4. 触发动作：删除主题家族

必须同步修正的文件：

- `shared/frontend/theme/README.md`
- 被删除主题家族的入口说明
- `docs/architecture` 下对应主题家族架构文档
- 若 `ai-standards` 中存在专门面向该主题家族的修正索引，也应同步清理

可选同步检查文件：

- 静态预览入口是否仍引用旧主题家族
- 主题总览文档中是否仍保留旧目录结构

需要避免的旧描述：

- 主题家族目录已删除，但文档和入口仍保留旧信息

## 5. 触发动作：重构主题结构

必须同步修正的文件：

- 被重构主题家族的 `README.md`
- 对应 `manifest`
- 入口页 `index.html`
- 相关架构文档
- 若修正范围发生变化，则同步更新当前文件

可选同步检查文件：

- 皮肤目录内部 README 是否仍符合新结构
- 预览页说明是否仍符合新结构

需要避免的旧描述：

- 文档还停留在旧的目录层级
- 入口页交互已变，但说明未更新
